# 네이버웍스 결재 서식 작성 가이드

네이버웍스에서 결재 문서를 처음 작성할 때는 **누가 읽고 무엇을 판단하거나 해야 하는지**부터 정합니다. 그 목적에 맞는 서식을 고른 뒤, 준비한 값과 본문을 해당 입력 칸에 옮깁니다.

## 1. 서식 고르기

| 필요한 일 | 우선 확인할 양식과 준비 자료 |
|---|---|
| 실행할 일에 대한 결정 받기 | **업무 기안**. 승인받을 결정·범위·근거와 승인 후 일정 |
| 다른 부서에 구체적인 작업 요청 | **업무 협조**. 상대 부서, 받을 결과물, 기한과 작업에 필요한 자료 |
| 진행 상황이나 완료 결과 공유 | **업무 보고**. 대상 업무·기간·집계 기준, 남은 조치와 판단 요청 유무 |
| 비용 정산이나 지급 요청 | **지출결의서**. 개인경비 사용·법인카드 사용·외부지급 요청 중 지급 형태, 품목별 금액과 증빙 |
| 채용·인사·근태 신청 | 모집 단계인지 채용 예정자 품의인지, 신규 신청인지 원신청 취소인지 확인하고 해당 전용 양식 선택 |
| 고객 문제 기록 | **소비자 클레임 발생서** 또는 **VOC 리포트**. 발생 내용, 고객 영향, 현재 대응, 필요한 증빙과 후속 조치 |

[서식별 사용 가이드 목록](../../plugins/approval-writing/skills/approval-forms/references/guide-index.md)에서 해당 가이드를 열면 준비 자료, 입력 순서와 작성 예시를 볼 수 있습니다. 업무 보고의 유형과 작성 방법은 [업무 보고 작성 가이드](work-report.md)에 있습니다. 실제 입력 항목·선택값은 본인의 작성 화면과 대조합니다.

## 2. 메모와 근거 준비하기

서식별 가이드에는 일반 작성 예시와 여러 조건이 겹칠 때의 가상 사례가 있습니다. AI는 이미 알려준 내용을 사용하고, 금액·기간·대상·승인 범위처럼 답에 따라 문서가 바뀌는 사항만 다시 묻습니다. 답을 받기 전에 초안을 요청하면 확인된 내용과 아직 확인할 입력값을 구분합니다.

- **목적과 읽는 사람**　결재자나 받는 부서가 알아야 할 내용과 해 줘야 할 일을 적습니다. 승인이나 판단이 필요한 범위도 함께 적습니다.
- **확인한 사실**　대상·기간·수량·금액과 단위, 기준 시점, 확인한 근거를 정리합니다. 이미 정한 일정과 희망 일정을 구분하고 확인 중인 값은 표시합니다.
- **화면에 넣을 자료**　이미 입력한 부서·선택값, 연결할 증빙과 선행 문서를 준비합니다. 계좌 정보와 민감한 인사 정보, 본인 동의는 네이버웍스에서 직접 처리합니다.

## 3. 직접 작성하거나 AI로 초안 받기

**직접 작성할 때**는 **네이버웍스 결재 → 문서 작성**에서 해당 서식을 열고, 가이드의 순서에 따라 제목과 화면의 입력값을 채웁니다. 본문 칸이 있으면 첫 문단에 결재받을 결정이나 상대방이 해야 할 일, 또는 공유할 핵심 결과를 적습니다.

직접 작성하거나 AI 초안을 다듬을 때는 [전체 결재서식 공통 작성·디자인 기준](../../plugins/approval-writing/skills/work-report/references/design.md)을 적용합니다. 첫인사와 요청 문구의 상황별 예시, 줄바꿈·글머리표, 모바일에서 표와 이미지를 사용하는 기준을 확인할 수 있습니다.

**AI로 초안을 받을 때**는 아래 요청을 회사에서 허용한 AI의 새 대화에 복사하고 대괄호를 채웁니다. 플러그인을 [설치](../../README.md)했다면 첫 줄에 `$approval-forms`를 붙입니다. 이미 서식을 골랐다면 서식명을 적고, 아직 고르지 않았다면 작성 목적을 알려 주세요.

```text
네이버웍스 결재 초안을 작성해 주세요.
서식명: [아는 경우 적기]
읽는 사람과 요청할 판단·행동: [팀장, 협조 부서 등 / 승인·회신·현황 공유 등]
업무 메모: [대상, 기간, 수량·금액, 근거와 합의한 내용]
이미 입력한 값: [부서, 날짜, 선택지 등]
첨부·연관문서: [직접 연결할 자료, 미확인 여부]
화면 입력값, 붙여 넣을 본문(본문 칸이 있는 경우), 작성자 확인 사항을 나눠 주세요.
본문의 기본 글꼴은 Sans Serif로 해 주세요. HTML 출력이면 바깥 div에 font-family:sans-serif를 지정해 주세요.
```

예를 들어 “출고팀에 포장자재 5개 품목의 실물 수량을 확인해 달라고 요청하려고 합니다. 11월 20일 15시까지 품목별 수량과 확인 시각을 댓글로 받으려 합니다. 품목 목록은 제가 직접 첨부합니다.”라고 요청하면 **업무 협조**에 맞춰 초안을 받을 수 있습니다. 추가 질문과 출력 방식은 [결재 작성 인터뷰와 출력 기준](../../plugins/approval-writing/skills/approval-forms/references/interview-output.md)을 따릅니다.

## 4. 작성 화면에 옮기고 결재자 관점에서 확인하기

1. **입력값 옮기기**　제목·부서·선택지·날짜·표 행을 각각 해당 칸에 넣습니다. 조건에 따라 나타나는 칸과 필수 표시는 화면에서 확인합니다.
2. **본문 붙여 넣기**　일반 본문은 **Editor**에 붙여 넣습니다. HTML 본문이면 해당 본문 에디터의 **HTML** 탭에 코드만 붙여 넣고 **Editor**로 전환해 제목·글꼴·줄바꿈·표를 확인합니다. HTML 탭이 없으면 AI에 Editor용 일반 본문을 요청합니다.
3. **결재자 입장에서 검토하기**　첫 문단에서 결정이나 요청 행동, 공유할 핵심을 찾을 수 있는지 확인합니다. 근거 자료가 판단 범위를 뒷받침하는지, 확인된 사실과 미확인·협의 중인 항목이 드러나는지, 후속 조치의 담당과 일정이 실제 합의에 맞는지 살핍니다.
4. **작성자가 직접 확인하기**　첨부를 실제로 연결했고 파일을 열 수 있는지, 연관문서와 결재선이 맞는지 확인합니다. 개인 정보와 동의는 본인이 화면에서 확인합니다. 추가 확인이 필요하면 임시 저장하고, 작성과 검토가 끝나면 상신합니다. 승인과 지급·근태 반영은 이후 해당 화면에서 확인합니다.
