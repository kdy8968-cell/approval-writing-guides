# 결재 작성 도우미

현재 요청에서 서식명(알고 있다면), 작성 목적, 결재자나 협조자가 할 일, 실제 메모·기한·증빙을 확인한다. 이전 채팅이나 별도 프로젝트 설정 없이 이 패키지의 가이드로 작성한다.

1. 기존 메모와 입력값에서 사용자가 원하는 결과를 확인한다. 승인할 결정은 업무 기안, 타 부서가 해 줄 일은 업무 협조, 상황·결과 공유는 업무 보고, 지출·지급 기록은 지출결의서부터 검토한다. 전용 서식이 있으면 실제 상황에 맞는 경로를 사용한다. 이미 서식이 정해졌고 목적에 맞으면 바로 작성한다.
2. [서식별 가이드 목록](references/guide-index.md)에서 고른 서식의 작성 순서와 예시를 읽는다. 업무 보고는 [업무 보고 스킬](../work-report/SKILL.md)을 적용한다. 가이드의 항목명과 선택지는 예시이며 회사별로 다르다. 사용자가 제공한 현재 작성 화면의 이름·순서·필수 조건을 우선한다. 작성 권한이나 조건부 항목이 결과에 영향을 주면 해당 화면에서 확인할 값만 남긴다.
3. [인터뷰와 출력 기준](references/interview-output.md)의 질문 기준과 해당 가이드의 분기를 적용한다. 자료가 충분하면 작성한다. 금액·기간·원신청·지급 유형·판단 요청처럼 결과를 바꾸는 공백이나 모순만 묶어 묻고, 답을 받은 뒤 완성한다. 사용자가 먼저 초안을 요청하면 확인된 부분과 미확인 값을 표시한다. 가상 사례는 가상으로 표시하고, 동의·합의·승인·실행 여부는 근거에 맞춰 표현한다.
4. 실제 입력 순서에 맞춰 **입력값 → 자유 본문(있는 경우) → 작성자 확인**을 제공한다. 제목과 본문 첫 문단에 독자가 이번 문서에서 결정하거나 확인할 일을 제시한다. 서식별 근거·조건·다음 조치 순서는 [인터뷰와 출력 기준](references/interview-output.md)을 따른다. HTML이나 일반 본문을 작성할 때 [공통 디자인 가이드](../work-report/references/design.md)를 적용한다. 본문은 기본 글꼴 Sans Serif로 작성한다. HTML은 바깥 `div`에 `font-family:sans-serif`를 지정한다.
5. 작성자 확인에는 실제 화면의 조건부 입력, 첨부·연관문서, 결재선, 필요한 동의 등 남은 작업만 적는다. 계좌·연락처·인사 식별 정보와 동의 선택은 필요한 경우 작성자가 네이버웍스에서 직접 입력·확인한다. 기안 초안의 작성과 임시 저장·상신·승인·지급·근태 반영 상태를 구분한다. 화면 입력이나 상신은 사용자가 그 작업을 따로 요청한 경우에만 진행한다.

서식 정보가 부족하면 대상 작성 화면의 항목과 실제 선택지를 사용자에게 확인하거나, 사용할 수 있는 읽기 도구로 해당 서식만 조회한다. 결재 문서 원장·타인의 초안·증빙을 서식 확인용으로 열 필요는 없다.
