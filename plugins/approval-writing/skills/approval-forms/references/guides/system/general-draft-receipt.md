# 일반 기안지 (수신) 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

기안할 안건과 결재 후 받을 대상이 정해져 있을 때 확인하는 서식입니다. 실제 안건에 전용 서식이 있다면 [서식별 가이드](../../guide-index.md)에서 해당 서식을 찾아 적용 여부를 먼저 확인합니다.

## 작성 전에 확인할 사항

- 결재받을 결정 한 가지는 무엇이고 어떤 자료로 판단할 수 있나요? 실행 범위와 시기를 함께 확인합니다.
- 승인 후 누가 무엇을 언제 맡나요? 이미 정해진 담당·일정과 승인 후 정할 내용을 구분합니다.
- 처리 결과를 어느 부서·역할이 받아야 하나요? 그 사람에게 전달할 내용과 결재선을 실제 화면에서 확인합니다.

## 작성 순서

1. **준비** — 어떤 결정을 받고 싶은지, 그 이유와 근거, 적용 대상·시기와 후속 조치를 정리합니다. 결재 후 내용을 받을 부서나 역할과 필요한 전달 범위를 확인합니다.
2. **서식 열기** — 네이버웍스 **결재 → 문서 작성**에서 **일반 기안지 (수신)**를 찾습니다. 본인 계정에 표시되지 않으면 소속 담당자에게 적용 대상과 작성 경로를 확인합니다.
3. **기안 내용 입력** — 화면에 보이는 항목 순서대로 안건과 근거를 옮깁니다. 본문이 있으면 첫 문단에 결정받을 사항을 적고, 근거와 승인 후 담당·일정을 이어 적습니다. 수신과 결재를 각각 설정하는 화면이라면 지정 목적에 맞는 사람을 확인합니다.
4. **제출 전후 확인** — 결정 요청, 결재선, 수신 대상과 첨부·연관문서를 화면에서 대조한 뒤 상신합니다. 처리 상태와 수신 대상에게 전달됐는지 확인합니다.

## 가상 작성 예시

업무지원팀이 요청서 누락을 줄이기 위해 11월 30일부터 한 주 동안 마감 시간과 담당 역할을 표시하는 공용 접수표를 시범 운영하려 합니다. 지난주 요청 20건 중 4건에서 마감 시간이 빠져 담당자가 다시 확인했습니다. 업무지원 담당이 표를 준비하고 승인 후 매장 접수 담당에게 운영 방법을 전달합니다. 시범 기간이 끝나면 마감 시간 누락 건수를 확인해 결과를 공유할 계획입니다.

| 준비 항목 | 초안 또는 확인할 값 |
|---|---|
| 제목 초안 | 요청 접수표 1주 시범 운영 기안 |
| 요청하는 결정 | 2026-11-30부터 1주일간 공용 접수표 시범 운영 승인 |
| 수신 대상 | 승인 후 운영 방법을 전달받을 매장 접수 담당 역할. 실제 대상과 지정 방식은 화면에서 확인합니다. |
| 첨부·연관문서 | 예시에서 연결할 문서는 없습니다. |

**본문 초안**

> 11월 30일부터 1주일간 마감 시간과 담당 역할을 표시하는 공용 접수표의 시범 운영을 승인해 주시기 바랍니다.
>
> 지난주 요청 20건 중 4건에서 마감 시간이 빠져 담당자가 다시 확인해야 했습니다. 업무지원 담당이 접수표를 준비하고, 승인 후 매장 접수 담당에게 입력 방법을 전달할 계획입니다. 시범 기간이 끝나면 마감 시간 누락 건수를 확인해 결과를 공유하겠습니다.

상신 후 결재 상태를 확인합니다. 처리되면 실제 수신 대상과 문서 전달 상태를 확인하고, 승인받은 범위에 따라 시범 운영을 준비합니다.

AI에 요청할 때는 `$approval-forms`에 위와 같이 승인받을 일, 근거, 기간, 후속 조치와 받을 역할을 알려 주세요. 실제 화면에서 본문·수신·결재 입력란을 확인하면 항목별로 초안을 정리할 수 있습니다.

## BEST 사례 · 수신 역할과 후속 일정이 아직 정해지지 않은 경우

가상으로 두 매장에서 시범 운영하려 하지만 한 매장만 담당 역할과 시작일을 확인했습니다. 다른 매장은 담당을 조율 중이며, 현재 작성 화면에서 수신을 지정하는 방식도 확인되지 않았습니다.

- 한 매장만 승인받을지, 두 매장 범위를 함께 올릴지 먼저 확인합니다. 한 매장 범위가 분명하면 “확인된 매장 한 곳에서 공용 접수표를 1주일간 시범 운영하도록 승인 요청드립니다.”라고 초안을 작성할 수 있습니다. 다른 매장은 `담당·시작일 협의 중`으로 표시합니다.
- 두 매장 동시 적용이 결정의 핵심이면 승인 범위와 실행 조건을 확인하기 전 완성본을 내지 않습니다. 수신할 역할이 확인되더라도 실제 사용자와 수신 설정 방식은 본인 화면에서 대조합니다.
- 처리 후 승인 범위와 실제 전달 대상·상태를 확인합니다. 확정된 매장과 날짜를 기준으로 후속 실행을 준비합니다.
