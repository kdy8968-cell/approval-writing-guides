# 증명서 신청 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

제출용 재직증명서를 발급받아야 할 때 사용합니다. 제출처가 요구하는 언어와 발급 조건을 먼저 확인합니다.

## 작성 전에 확인할 사항

- 제출처에서 한글 또는 영문 중 어떤 재직증명서를 요구하나요?
- 발급 용도를 어떻게 적으면 되나요? 제출처에 필요한 범위까지 확인합니다.
- 제출 기한이나 부수·형식에 별도 조건이 있나요? 별도 칸이 있는지는 현재 화면에서 확인합니다.

## 작성 순서

1. **준비** — 필요한 증명서 종류와 발급 용도를 준비합니다. 제출처·부수·형식에 지정 조건이 있으면 확인해 둡니다.
2. **서식 열기** — 네이버웍스 결재에서 **문서 작성 → 증명서 신청**을 엽니다.
3. **신청 내용 입력** — **제목**을 입력하고 **증명서 항목**에서 제출처가 요구하는 유형을 선택합니다. 재직증명서 한글본과 영문본은 예시입니다. **발급 용도**에 증명서를 어디에 어떤 목적으로 제출하는지 필요한 범위에서 씁니다.
4. **제출 전후 확인** — 선택한 증명서 종류와 발급 용도, 결재선을 대조한 뒤 상신합니다. 처리 상태를 확인하고 발급된 증명서의 언어와 기재 내용이 제출 조건에 맞는지 확인합니다.

## 가상 작성 예시

외부 교육기관이 등록 서류로 영문 재직증명서를 요구합니다. 신청서에 개인 식별정보를 추가할 필요는 없다는 전제입니다.

| 화면 항목 | 입력값 |
|---|---|
| 제목 | 교육기관 제출용 영문 재직증명서 신청 |
| 증명서 항목 | 재직증명서(영문) |
| 발급 용도 | 외부 교육기관 교육 과정 등록 서류 제출용 |

상신 후 증명서 신청의 처리 상태를 확인합니다. 발급된 파일을 열어 영문으로 발급됐는지, 본인 정보와 제출 조건이 일치하는지 대조합니다.

AI에 요청할 때는 `$approval-forms`에 “외부 교육 과정에 등록하려고 영문 재직증명서를 신청합니다. 제목과 발급 용도를 한 줄씩 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 제출 조건이 아직 확인되지 않은 경우

가상으로 두 제출처에서 증명서를 요청했습니다. 국내 교육기관은 한글본을 요구하고, 해외 기관은 영문본 외에 별도 서식 또는 발급일 기준이 있는지 회신 전입니다. 제출처별 요구 언어, 부수와 발급일 조건을 확인합니다.

- 조건이 확인된 건은 `교육기관 제출용 한글 재직증명서 신청`과 같은 제목과 용도를 작성할 수 있습니다. 해외 기관 건은 `해외 기관 제출용`이라는 용도 초안을 남기고 언어와 별도 형식은 `확인 필요`로 둡니다.
- 화면의 선택지 외에 다른 증명서나 별도 형식이 필요하면 발급 담당자에게 경로를 확인합니다. 두 제출처의 요구를 한 건으로 충족할 수 있다고 가정하지 않습니다.
- 발급 후 파일별 언어, 본인 정보, 발급일과 실제 제출처 요구사항을 대조합니다.
