# 근무 결과 신청 취소 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

이미 올린 근무 결과 신청을 취소해야 할 때 사용합니다. 비슷한 제목으로 여러 근무일을 신청했다면 기준일과 신청 구분부터 대조합니다.

## 작성 전에 확인할 사항

- 취소하려는 원신청의 기준일, 제목과 신청 구분은 무엇인가요? 문서번호를 알면 함께 확인합니다.
- 취소 사유가 중복 등록, 기준일 착오 또는 다른 사유 중 무엇인가요? 실제로 확인한 오류만 씁니다.
- 취소한 뒤 다시 신청해야 하나요? 재신청 여부가 미정이면 취소 사유에 확정된 조치로 적지 않습니다.

## 작성 순서

1. **준비** — 원신청의 제목, 기준일, 신청 구분과 취소 사유를 준비합니다. 문서번호가 있으면 조회할 때 참고합니다.
2. **서식 열기** — 네이버웍스 결재에서 **문서 작성 → 근무 결과 신청 취소**를 엽니다.
3. **원신청 연결** — **취소 대상 문서 → 문서 조회**에서 제목, 문서번호, 작성자, 기준일과 근무 내용을 대조하고 취소할 원신청을 선택합니다. 대상이 조회되지 않으면 원신청 상태와 사용 가능한 경로를 확인합니다.
4. **취소 내용 입력** — **제목**과 **사유**를 입력합니다. 증빙이 필요하면 **파일 첨부**에 연결합니다.
5. **제출 전후 확인** — 취소 대상의 기준일과 결재선을 대조한 뒤 상신합니다. 결재 상태와 근로 시간 현황의 실제 반영 여부를 확인합니다. 다시 신청해야 하는 경우 적용할 절차를 확인한 뒤 진행합니다.

## 가상 작성 예시

실제 근무일은 11월 12일인데 기준일을 11월 11일로 선택해 근무 결과를 신청했습니다. 기준일을 잘못 넣은 신청을 취소하려고 합니다.

| 화면 항목 | 입력값 또는 확인할 값 |
|---|---|
| 제목 | 11월 11일 근무 결과 신청 취소 요청 |
| 취소 대상 문서 | **문서 조회**에서 기준일이 2026-11-11인 본인의 원신청을 대조해 선택합니다. |
| 사유 | 11월 12일 근무 결과를 신청하면서 기준일을 11월 11일로 잘못 선택했습니다. 기준일이 11월 11일인 신청의 취소를 요청합니다. |
| 파일 첨부 | 예시에서는 비워 둡니다. |

상신 후 취소 신청의 원신청 연결과 처리 상태를 확인합니다. 처리 후 11월 11일 근로 시간 현황을 확인하고, 11월 12일 신청이 필요한 경우 해당 날짜의 경로를 확인합니다.

AI에 요청할 때는 `$approval-forms`에 “실제 근무일은 11월 12일입니다. 11월 11일로 잘못 올린 근무 결과 신청의 제목과 취소 사유를 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 같은 기준일의 신청이 여러 건인 경우

가상으로 11월 12일에 신청 두 건이 있고, 그중 18:30으로 올린 기록을 취소해 18:00으로 다시 신청하려고 합니다. 기준일만 같다면 취소 대상을 결정할 수 없습니다. **문서 조회**에서 문서번호, 신청 구분, 종료 시각과 처리 상태를 확인합니다.

- 확인 전 사유 초안은 “11월 12일 근무의 종료 시각을 18:30으로 잘못 입력해 해당 신청의 취소를 요청합니다.”로 둘 수 있습니다. 원신청 한 건이 식별될 때까지 연결과 상신은 보류합니다.
- 취소 가능 상태와 정정 신청 경로는 현재 화면에서 확인합니다. 18:00으로 이미 제출한 정정 신청이 있는지 확인하고 중복 제출을 피합니다.
- 처리 후 취소 요청에 연결된 문서가 맞는지, 11월 12일 근로 시간 현황에 어떤 기록이 남았는지 대조합니다.
