# 휴가 신청 (아르바이트) 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

아르바이트 직원이 휴가를 신청할 때 확인하는 서식입니다. 본인에게 제공되는 휴가 종류와 신청 단위를 먼저 확인합니다.

## 작성 전에 확인할 사항

- 본인 작성 목록에 **휴가 신청 (아르바이트)**가 보이나요? 사용할 수 있는 휴가 종류와 단위를 화면에서 확인합니다.
- 쉬려는 날짜와 시작·종료 시각이 언제인가요? 확정된 날짜와 협의 중인 날짜를 구분합니다.
- 사유나 증빙이 필요한가요? 일정 조정이 있었다면 실제로 합의된 내용을 확인합니다.

## 작성 순서

1. **준비** — 요청하는 휴가 종류, 시작·종료 날짜와 시간, 필요한 사유를 정리합니다. 업무 조율이 필요하면 실제로 합의된 내용만 기록합니다.
2. **서식 열기** — 네이버웍스 **결재 → 문서 작성**에서 **휴가 신청 (아르바이트)**을 찾습니다. 본인 계정에서 양식이 보이지 않으면 적용 대상과 신청 경로를 소속 담당자에게 확인합니다.
3. **휴가 내용 입력** — 화면에서 가능한 종류와 단위를 확인해 선택하고, 기간과 필요한 사유를 해당 칸에 옮깁니다. 증빙이 필요한 경우 화면에서 요구하는 범위를 확인합니다.
4. **제출 전후 확인** — 시작·종료 일시와 화면의 차감·잔여 값, 결재선을 확인한 뒤 상신합니다. 처리 상태와 휴가 일정 반영을 확인합니다.

## 가상 작성 예시

아르바이트 직원이 개인 일정으로 11월 24일 13:00~17:00 근무 시간의 휴가를 신청하려고 합니다. 휴가 종류와 시간 단위가 해당 화면에서 선택 가능한지는 확인 전입니다.

| 준비 항목 | 초안 또는 확인할 값 |
|---|---|
| 제목 초안 | 11월 24일 아르바이트 휴가 신청 |
| 희망 휴가 일시 | 2026-11-24 13:00~17:00 |
| 사유 초안 | 개인 일정으로 11월 24일 13:00~17:00 근무 시간의 휴가를 신청합니다. |
| 화면에서 확인 | 해당 휴가 종류, 시간 단위 신청 가능 여부, 표시되는 차감·잔여 값과 증빙 필요 여부를 확인합니다. |

선택할 수 있는 종류와 단위가 희망 일시와 맞는지 확인하고 상신합니다. 처리 후 휴가 일정과 화면의 차감·잔여 값을 대조합니다.

AI에 요청할 때는 `$approval-forms`에 “11월 24일 13~17시 개인 일정으로 휴가를 신청합니다. 화면에 [실제 항목 이름]이 보입니다. 제목과 사유를 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 휴가 기간에 근무하지 않는 날이 포함된 경우

가상으로 11월 24~26일 쉬어야 하지만 근무표에는 24일과 26일만 근무가 잡혀 있습니다. 24일은 근무 전체, 26일은 마지막 두 시간만 비울 예정입니다. 날짜별 근무와 휴가 요청 범위를 표나 메모에서 대조합니다.

- 확실한 날짜와 희망 시간은 초안에 남깁니다. 휴가 종류와 단위, 25일 처리, 실제 차감 값은 `확인 필요`로 둡니다. 달력의 시작·종료일 차이만으로 차감 일수를 계산하지 않습니다.
- 본인 화면에서 날짜·단위를 서로 다르게 입력할 수 있는지 확인합니다. 신청 범위가 희망과 다르게 표시되면 소속 담당자에게 처리 경로를 확인한 뒤 제출합니다.
- 처리 후 24일과 26일의 반영 범위, 25일 근무표, 실제 표시되는 잔여 값을 각각 확인합니다.
