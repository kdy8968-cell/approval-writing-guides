# 근무 결과 신청 (아르바이트) 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

아르바이트 직원이 이미 근무한 날의 실제 근무 결과를 신청할 때 확인하는 서식입니다. 앞으로의 근무 일정은 [근무 일정 신청 (아르바이트)](part-time-work-schedule-request.md)를 확인합니다.

## 작성 전에 확인할 사항

- 본인 작성 목록에 **근무 결과 신청 (아르바이트)**이 보이나요? 현재 화면의 양식 이름을 확인합니다.
- 어느 날 몇 시부터 몇 시까지 실제로 근무했으며, 휴게는 언제였나요? 기록을 변경하려면 기존 값과 실제 값이 어떻게 다른지 확인합니다.
- 왜 결과 신청이 필요한가요? 근무일과 사유는 확인한 기록을 기준으로 씁니다.

## 작성 순서

1. **준비** — 실제 근무일, 시작·종료 시각, 휴게시간과 신청 사유를 정리합니다. 기존 기록과 달라진 부분이 있다면 해당 날짜와 차이를 확인합니다.
2. **서식 열기** — 네이버웍스 **결재 → 문서 작성**에서 **근무 결과 신청 (아르바이트)**을 찾습니다. 화면에 표시되는 서식 이름과 자신의 적용 대상을 확인합니다. 목록에 없으면 소속 담당자에게 사용 가능한 경로를 확인합니다.
3. **근무 내용 입력** — 실제 화면에서 신청 구분, 기준일과 시간에 해당하는 입력란을 확인하고 준비한 내용을 옮깁니다. 휴게시간과 증빙은 해당 입력란이 있는 경우 반영합니다.
4. **제출 전후 확인** — 실제 시각·휴게와 화면의 인정 시간을 대조하고, 차이가 있으면 입력과 적용 기준을 확인한 뒤 상신합니다. 결재 상태와 해당일 근무 현황의 반영 여부를 확인합니다.

## 가상 작성 예시

아르바이트 직원이 11월 12일 12:00–17:00에 근무했습니다. 14:30–15:00에 휴게했고 마감 때 퇴근 기록을 남기지 못했습니다.

| 준비 항목 | 초안 또는 확인할 값 |
|---|---|
| 제목 초안 | 11월 12일 아르바이트 근무 결과 신청 |
| 실제 근무 기록 | 2026-11-12 12:00–17:00, 휴게 14:30–15:00 |
| 사유 초안 | 11월 12일 마감 후 퇴근 기록을 남기지 못했습니다. 실제 근무는 12:00–17:00이며 14:30–15:00에 휴게했습니다. 해당일 근무 결과 반영을 신청합니다. |
| 화면에서 확인 | 본인에게 표시되는 신청 구분, 일시·휴게 입력란과 계산값을 확인한 뒤 옮깁니다. |

상신 후 11월 12일 결과로 접수됐는지 확인합니다. 처리 후 근무 현황과 시스템 인정 시간을 대조합니다.

AI에 요청할 때는 `$approval-forms`에 “11월 12일 12–17시 근무, 14시 30분부터 30분 휴게입니다. 퇴근 기록이 누락됐습니다. 화면에는 [실제 항목 이름]이 보입니다. 항목에 맞춰 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 같은 날 여러 번 근무한 경우

가상으로 11월 14일에 10:00–13:00, 16:00–19:00 두 구간에 근무했습니다. 근무표에는 두 구간이 있고 화면에는 10:00 출근과 19:00 퇴근만 보입니다. 13:00–16:00 사이에 실제로 업무를 하지 않았는지와 각 구간의 휴게 여부를 확인합니다.

- 확인된 시간대는 두 구간 그대로 준비합니다. 중간 시간의 상태와 화면에서 구간을 나눠 입력할 수 있는지가 확인되기 전에는 10:00–19:00 연속 근무 또는 하나의 휴게시간으로 확정하지 않습니다.
- 본인 화면에서 사용할 수 있는 기록 방식과 인정 시간을 확인합니다. 구간을 구분할 수 없다면 소속 담당자에게 해당 근무일의 정정 경로를 확인합니다. 사유 초안에는 “당일 근무한 두 구간을 기록에 반영하려 합니다.”와 확인한 구간을 적을 수 있습니다.
- 처리 후 두 근무 구간의 누락·중복과 인정 시간을 실제 기록과 대조합니다.
