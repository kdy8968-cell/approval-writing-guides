# 근무 결과 신청 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

이미 근무한 날의 실제 시간을 반영하거나 해당일의 근무 결과를 변경해야 할 때 사용합니다. 앞으로의 근무 계획을 신청할 때는 [근무 일정 신청](work-schedule-request.md)을 확인합니다.

## 작성 전에 확인할 사항

- 어느 날짜의 근무 결과를 신청하나요? 자정을 넘긴 근무라면 시작일과 종료일을 각각 확인합니다.
- 실제 시작·종료 시각과 휴게시간은 얼마인가요? 기존 기록을 변경하려면 어떤 값이 달랐는지도 확인합니다.
- 신청 사유에 근거가 필요한가요? 확인한 기록과 추정한 내용을 구분합니다.

## 작성 순서

1. **준비** — 실제 근무일, 시작·종료 시각, 휴게시간과 신청 사유를 준비합니다. 시간 변경이 필요한 경우 기존 기록과 실제 근무 내용을 대조합니다.
2. **서식 열기** — 네이버웍스 결재에서 **문서 작성 → 근무 결과 신청**을 엽니다.
3. **근무 내용 입력** — **제목**, **기준일**, **사유**를 입력합니다. 기준일을 선택한 뒤 화면에 표시되는 신청 구분과 시간 입력란을 확인해 실제 근무 내용을 넣습니다. 필요한 증빙은 **파일 첨부**에 연결합니다.
4. **제출 전후 확인** — 기준일과 실제 시각, 휴게와 화면의 인정 시간, 결재선을 대조한 뒤 상신합니다. 결재 상태를 확인한 뒤 근로 시간 현황에 해당일 내용이 반영됐는지 확인합니다. 반려된 경우 해당일의 근로 시간에 어떻게 반영되는지 화면과 담당 안내를 확인합니다.

## 가상 작성 예시

11월 12일 실제 근무는 09:00–18:00, 휴게는 12:00–13:00입니다. 퇴근 기록을 남기지 못해 해당일 근무 결과를 신청합니다.

| 화면 항목 | 입력값 또는 확인할 값 |
|---|---|
| 제목 | 11월 12일 근무 결과 신청 |
| 기준일 | 2026-11-12 |
| 사유 | 11월 12일 퇴근 기록을 남기지 못했습니다. 실제 근무는 09:00–18:00이며 12:00–13:00에 휴게했습니다. 해당일 근무 결과 반영을 신청합니다. |
| 파일 첨부 | 예시에서는 비워 둡니다. |
| 기준일 선택 후 추가 항목 | 표시되는 신청 구분과 시간 입력란에 실제 근무일·시각·휴게시간을 대조합니다. 화면의 인정 시간은 제출 전에 직접 확인합니다. |

상신 후 근무 결과 신청 문서의 기준일과 상태를 확인합니다. 결재 처리 후에는 11월 12일 근로 시간 현황의 시작·종료 시각과 인정 시간을 대조합니다.

AI에 요청할 때는 `$approval-forms`에 “11월 12일 퇴근 기록이 누락됐습니다. 실제 09–18시 근무, 12–13시 휴게입니다. 신청 제목과 사유를 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 자정을 넘기거나 기록이 다른 경우

가상 메모에 근무 시작이 11월 12일 21:00, 종료가 13일 01:00이라고 적혀 있고 출퇴근 기록에는 13일 00:40이 표시됩니다. 두 값을 출처와 함께 적어 두고, 실제 종료 시각과 휴게시간을 확인합니다. 기준일을 어느 날짜로 선택해야 하는지도 화면에서 확인합니다.

- 사유 초안에는 “11월 12일 21:00에 시작한 근무가 자정을 넘겼으며, 종료 시각은 출퇴근 기록과 근무 메모를 대조 중입니다.”라고 적을 수 있습니다. 기준일·종료 시각·인정 시간은 확인 전 입력값으로 확정하지 않습니다.
- 날짜가 다른 두 시각을 같은 날로 바꿔 쓰거나 시스템 인정 시간을 임의 계산해 적지 않습니다. 제출 전에 시작·종료 날짜와 시각, 휴게, 화면 계산을 대조합니다.
- 처리 후 관련 날짜의 근로 시간 현황을 열어 근무 시간대가 누락되거나 중복 반영된 부분이 없는지 확인합니다.
