# 부재 일정 취소 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

이미 올린 부재 일정을 취소해야 할 때 사용합니다. 취소할 원신청이 여러 건이라면 날짜와 부재 항목을 먼저 확인합니다.

## 작성 전에 확인할 사항

- 취소하려는 원신청의 제목, 기간과 부재 항목이 무엇인가요? 문서번호를 알면 함께 확인합니다.
- 전체 일정을 취소하는 건가요? 일정 일부만 변경하려면 원신청 화면에서 지원하는 처리 범위를 먼저 확인합니다.
- 취소 사유가 무엇이며 새 일정도 신청해야 하나요? 새 일정이 미정이면 사유에 확정 일정으로 적지 않습니다.

## 작성 순서

1. **준비** — 원신청의 제목, 부재 종류, 기간과 취소 사유를 준비합니다. 문서번호가 있으면 조회할 때 참고합니다.
2. **서식 열기** — 네이버웍스 결재에서 **문서 작성 → 부재 일정 취소**를 엽니다.
3. **원신청 연결** — **취소 대상 문서 → 문서 조회**에서 원신청을 찾습니다. 제목이 같아도 문서번호, 작성자, 부재 종류와 기간을 대조한 뒤 본인이 취소할 문서 한 건을 선택합니다.
4. **사유 입력** — **제목**에 어떤 부재를 취소하는지 적고, **사유**에 취소하는 이유를 간단히 씁니다. 증빙이 필요하면 **파일 첨부**에 연결합니다.
5. **제출 전후 확인** — 취소 대상과 결재선을 다시 확인해 상신합니다. 취소 문서의 처리 상태와 부재 일정·잔여일수의 실제 반영 여부를 각각 확인합니다. 원신청이 조회되지 않으면 해당 문서의 상태와 취소 경로를 먼저 확인합니다.

## 가상 작성 예시

11월 19일 오후 외근으로 등록한 거래처 방문이 취소됐습니다. 같은 주에 다른 외근 신청도 있으므로 원신청의 날짜와 시간을 확인합니다.

| 화면 항목 | 입력값 또는 확인할 값 |
|---|---|
| 제목 | 11월 19일 외근 일정 취소 요청 |
| 취소 대상 문서 | **문서 조회**에서 본인이 작성한 2026-11-19 14:00~16:00 외근 원신청을 대조해 선택합니다. |
| 사유 | 거래처 방문 일정이 취소되어 11월 19일 14:00~16:00에 신청한 외근을 취소 요청합니다. |
| 파일 첨부 | 예시에서는 비워 둡니다. |

상신 후 취소 신청의 대상이 11월 19일 원신청인지 확인합니다. 처리 완료 후 그 외근이 부재 일정에서 어떻게 표시되는지 확인합니다.

AI에 요청할 때는 `$approval-forms`에 “거래처 방문 취소로 11월 19일 14시부터 16시까지 신청한 외근을 취소합니다. 제목과 사유를 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 일부 날짜만 취소하는 경우

가상으로 11월 19~20일 외근을 한 문서로 신청했고, 20일 방문만 취소됐습니다. **문서 조회**에서 두 날짜가 묶인 원신청과 별도 원신청이 있는지 대조합니다. 묶인 원신청만 있다면 20일만 취소할 수 있는 경로를 확인합니다.

- 초안 사유에는 “11월 20일 방문이 취소됐습니다. 19일 외근은 예정대로 진행합니다.”라고 적을 수 있습니다. 원신청과 취소 범위가 확인될 때까지 `취소 대상 문서`를 선택하지 않습니다.
- 20일만 처리하는 방법이 화면에서 확인되면 해당 범위로 작성합니다. 원신청 전체 취소와 재신청이 필요하다면 담당자가 확인한 절차에 따릅니다.
- 처리 후 19일 일정이 남아 있는지와 20일 일정의 취소가 반영됐는지를 각각 확인합니다.
