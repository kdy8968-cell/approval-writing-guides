# 근무 일정 신청 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

앞으로 근무할 날짜와 시간의 일정을 신청할 때 확인하는 서식입니다. 이미 근무한 날의 기록을 처리하려면 [근무 결과 신청](work-result-request.md)을 확인합니다.

## 작성 전에 확인할 사항

- 신청하려는 날짜와 시작·종료 시각, 휴게가 어떻게 되나요? 자정을 넘기면 시작일과 종료일을 확인합니다.
- 새 일정을 신청하나요, 기존 일정을 바꾸려 하나요? 변경이면 기존 일정과 요청 일정을 함께 준비합니다.
- 계획 일시가 확정됐나요? 담당자와 합의한 사항이 있으면 협의 범위를 확인합니다.

## 작성 순서

1. **준비** — 신청할 근무일과 계획한 시작·종료 시각, 필요한 휴게시간과 일정 신청 사유를 준비합니다. 날짜를 넘기는 일정이라면 시작일과 종료일을 각각 적습니다.
2. **서식 열기** — 네이버웍스 **결재 → 문서 작성**에서 **근무 일정 신청**을 찾습니다. 본인 계정에 표시되지 않으면 적용 대상과 신청 경로를 소속 담당자에게 확인합니다.
3. **일정 입력** — 실제 화면에서 선택할 일정 구분과 시간 단위를 확인하고 계획한 날짜·시각을 입력합니다. 사유를 적는 칸에는 일정 신청 이유와 업무에 필요한 변경 내용을 씁니다.
4. **제출 전후 확인** — 신청한 날짜·시각과 화면에 표시되는 일정, 결재선을 확인한 뒤 상신합니다. 처리 상태와 실제로 일정이 반영됐는지 확인합니다.

## 가상 작성 예시

11월 24일 오전 입고 확인을 맡아 08:00–17:00 근무 일정이 필요합니다. 계획한 휴게는 12:00–13:00입니다.

| 준비 항목 | 초안 또는 확인할 값 |
|---|---|
| 제목 초안 | 11월 24일 근무 일정 신청 |
| 계획한 근무 일시 | 2026-11-24 08:00–17:00, 휴게 12:00–13:00 |
| 사유 초안 | 11월 24일 오전 입고 확인을 위해 08:00–17:00 근무 일정을 신청합니다. 휴게는 12:00–13:00로 계획했습니다. |
| 화면에서 확인 | 실제로 선택할 수 있는 일정 구분, 일시·휴게 입력란과 승인 전 일정 표시를 확인합니다. |

상신 후 일정 신청 상태를 확인합니다. 처리 후 해당 날짜의 일정이 요청한 시각으로 표시되는지 대조합니다.

AI에 요청할 때는 `$approval-forms`에 “11월 24일 입고 확인을 위해 08–17시 근무, 12–13시 휴게를 계획합니다. 화면의 [실제 항목 이름]에 맞춰 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 기존 일정을 자정을 넘기는 시간대로 바꾸는 경우

가상으로 11월 26일 15:00–24:00 일정을 재고 조사에 맞춰 26일 17:00부터 27일 02:00까지로 바꾸려 합니다. 원래 일정은 근무표에 있고, 변경안의 휴게 시각은 협의 중입니다.

- 사유 초안에는 “재고 조사에 맞춰 11월 26일 기존 일정을 26일 17:00–27일 02:00로 변경하려 합니다.”라고 적을 수 있습니다. 휴게 시각과 인정 예정 시간은 확인 전 확정하지 않습니다.
- 본인 화면에서 다음 날 종료를 어떻게 입력하는지, 기존 일정과 중복이 발생하는지, 변경을 어디에서 신청하는지 확인합니다. 정확한 시작·종료 날짜나 근무 범위가 화면에서 확인되지 않으면 상신 전에 적용 경로를 확인합니다.
- 처리 후 26일과 27일 근무표를 열어 변경 일정이 맞는지, 기존 일정이 중복 표시되는지 대조합니다.
