# 부재 일정 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

연차, 출장, 외근처럼 예정된 부재를 새로 신청할 때 사용합니다. 기존에 신청한 부재를 취소하려면 [부재 일정 취소](absence-cancellation.md)를 사용합니다.

## 작성 전에 확인할 사항

- 신청할 부재 종류가 무엇이며 시작일과 종료일은 언제인가요? 하루보다 짧다면 실제 시작·종료 시각도 확인합니다.
- 업무 인계가 필요한가요? 인계가 이미 정해졌다면 대상 업무와 맡기로 한 역할을 확인합니다.
- 증빙이나 관련 문서가 필요한 부재인가요? 실제로 연결할 자료가 있는지 확인합니다.

## 작성 순서

1. **준비** — 부재 종류와 실제 시작·종료 일시를 정리합니다. 업무 인수인계가 필요하면 연락받을 역할과 진행 중인 일도 정리해 둡니다.
2. **서식 열기** — 네이버웍스 결재에서 **문서 작성 → 부재 일정**을 엽니다.
3. **신청 내용 입력** — **제목**, **부재 항목**, **사유**를 입력합니다. 부재 항목을 고른 뒤 날짜·시간과 신청 단위를 화면에 맞춰 선택합니다. 부재 항목의 예로 연차·출장·외근이 있습니다. 실제 선택지와 신청 단위는 화면에서 확인합니다.
4. **관련 자료 확인** — 필요한 **파일 첨부**와 **연관문서**를 연결합니다. **결재 위임**이나 부재 상태를 설정해야 한다면 화면의 **상태 설정 바로 가기**에서 본인 설정을 확인합니다.
5. **제출 전후 확인** — 날짜, 신청 단위와 화면에 표시되는 차감·잔여 값, 결재선을 대조한 뒤 상신합니다. 결재 상태와 부재 일정에 반영된 날짜를 확인합니다.

## 가상 작성 예시

11월 23일 하루 연차를 신청합니다. 사유는 개인 일정이며, 진행 중인 배송 확인은 직전 근무일까지 마무리하기로 했습니다. 증빙과 연관문서는 없습니다.

| 화면 항목 | 입력값 또는 확인할 값 |
|---|---|
| 제목 | 11월 23일 연차 신청 |
| 부재 항목 | 연차 |
| 날짜·시간 | 2026-11-23 하루를 신청합니다. 연차를 고른 뒤 날짜와 단위를 화면에서 확인합니다. |
| 사유 | 개인 일정으로 11월 23일 하루 연차를 신청합니다. 진행 중인 배송 확인은 직전 근무일까지 마무리하겠습니다. |
| 결재 위임 | 본인 상태 설정을 확인합니다. |
| 파일 첨부·연관문서 | 예시에서는 비워 둡니다. |

상신 후 원래 의도한 날짜로 접수됐는지 확인합니다. 결재가 처리되면 부재 일정과 화면에 표시되는 잔여 일수의 반영 여부를 확인합니다.

AI에 요청할 때는 `$approval-forms`에 “11월 23일 하루 연차를 신청합니다. 사유는 개인 일정이고 배송 확인은 직전 근무일까지 마무리할 계획입니다. 제목과 사유를 작성해 주세요.”라고 적을 수 있습니다.

## BEST 사례 · 날짜와 단위가 섞인 경우

가상 메모에 “11월 23일은 오전만 연차, 24일은 하루 연차, 25일은 출장 가능성이 있음”이라고 적혀 있습니다. 먼저 23일의 실제 시작·종료 시각과 23일·24일의 신청 단위가 화면에서 한 건으로 입력되는지 확인합니다. 25일 출장은 일정이 확정되는지 확인합니다.

- 23일 시각이나 신청 단위를 모르면 날짜 선택값과 차감 일수는 `확인 필요`로 둡니다. 24일의 하루 연차처럼 분명한 값은 초안에 남길 수 있습니다.
- 25일 출장은 협의 중으로 표시하고 연차 기간에 합산하지 않습니다. 화면에서 서로 다른 항목이나 단위를 따로 신청해야 하는지 확인합니다.
- 제출 전 선택한 날짜·단위를 근무표와 맞춰 봅니다. 처리 후 23일과 24일의 표시 및 화면에 제공되는 잔여 값이 각각 신청과 일치하는지 대조합니다.
