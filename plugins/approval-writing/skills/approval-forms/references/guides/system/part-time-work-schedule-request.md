# 근무 일정 신청 (아르바이트) 작성 가이드

> 공개용 작성 예시입니다. 이용할 수 있는 서식과 입력 항목은 조직 설정·계정에 따라 다릅니다. 실제 화면과 소속 조직의 기준을 확인합니다.

아르바이트 직원이 앞으로 근무할 일정을 신청할 때 확인하는 서식입니다. 이미 근무한 날은 [근무 결과 신청 (아르바이트)](part-time-work-result-request.md)를 확인합니다.

## 작성 전에 확인할 사항

- 본인 화면에 **근무 일정 신청 (아르바이트)**이 보이나요? 사용할 양식 이름을 확인합니다.
- 어느 날짜의 근무를 몇 시부터 몇 시까지 계획하나요? 휴게 시각과 기존 일정이 있으면 함께 확인합니다.
- 요청한 일정은 담당자와 합의됐나요? 협의 중이라면 사유에 확정 일정으로 적지 않습니다.

## 작성 순서

1. **준비** — 계획한 근무일과 시작·종료 시각, 필요한 휴게시간과 신청 사유를 준비합니다. 변경 신청이라면 원래 일정과 요청하는 일정을 각각 적어 둡니다.
2. **서식 열기** — 네이버웍스 **결재 → 문서 작성**에서 **근무 일정 신청 (아르바이트)**을 찾습니다. 화면에 보이지 않으면 소속 담당자에게 본인에게 적용되는 경로를 확인합니다.
3. **일정 입력** — 화면에서 선택 가능한 일정 구분과 시간 단위를 확인합니다. 날짜·시간과 필요한 사유를 실제 입력란에 옮기고, 화면이 계산한 시간이 있다면 계획한 일정과 대조합니다.
4. **제출 전후 확인** — 날짜, 기존 일정과의 중복, 결재선을 확인한 뒤 상신합니다. 처리 상태와 확정된 일정을 확인합니다.

## 가상 작성 예시

아르바이트 직원이 11월 25일 재고 조사 지원을 위해 14:00~19:00 근무 일정을 신청하려 합니다. 계획한 휴게는 16:00~16:30입니다.

| 준비 항목 | 초안 또는 확인할 값 |
|---|---|
| 제목 초안 | 11월 25일 아르바이트 근무 일정 신청 |
| 계획한 근무 일시 | 2026-11-25 14:00~19:00, 휴게 16:00~16:30 |
| 사유 초안 | 11월 25일 재고 조사 지원을 위해 14:00~19:00 근무 일정을 신청합니다. 휴게는 16:00~16:30으로 계획했습니다. |
| 화면에서 확인 | 본인에게 표시되는 일정 구분, 날짜·시각·휴게 입력란과 기존 일정 중복 여부를 확인합니다. |

상신 후 신청 대상일과 상태를 확인합니다. 처리 후 확정된 일정과 실제 근무 때 확인할 시각을 대조합니다.

AI에 요청할 때는 `$approval-forms`에 “11월 25일 재고 조사 지원으로 14~19시 근무를 계획합니다. 휴게는 16시부터 30분이고, 화면에 [실제 항목 이름]이 보입니다.”라고 적을 수 있습니다.

## BEST 사례 · 다른 직원과 일정을 바꾸려는 경우

가상으로 본인의 11월 25일 14:00~19:00 근무를 27일 09:00~14:00로 바꾸려 합니다. 상대 직원은 변경 가능 여부를 답하지 않았고, 근무표에도 기존 일정이 남아 있습니다.

- 초안에는 본인의 기존 일정과 희망 일정을 각각 적고, 상대와의 교대는 `회신 대기`로 둡니다. 상대의 근무 일정이나 동의를 대신 확정하지 않습니다.
- 본인 화면에서 일정 변경으로 신청할 수 있는지, 기존 일정을 어떻게 처리하는지 확인합니다. 교대가 전제인 요청이면 상대 회신과 실제 적용 경로를 확인한 뒤 상신합니다.
- 처리 후 본인 근무표의 25일과 27일 표시를 대조합니다. 다른 직원의 일정은 소속 담당자가 확인한 결과를 기준으로 합니다.
