# 명함 신청 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

새 명함을 만들거나 부서·직책·근무지 등의 표시를 바꿀 때 사용합니다. 명함에 실제로 인쇄될 정보를 신청자가 먼저 대조하세요.

## 작성 전에 준비하기

명함에 쓸 부서명, 직책, 근무지, 한글·영문 이름 표기와 연락처, 업무용 이메일을 확인합니다.

### 메모에서 빠진 내용만 확인하기

- **신규 명함**이면 처음 인쇄할 이름과 조직·근무지 표기를 확인합니다. **정보 변경**이면 바뀐 값과 유지할 값을 구분하고 인쇄할 모든 값을 다시 대조합니다.
- **다른 사람의 명함을 준비**하면 신청자 칸에 넣을 사람과 명함에 인쇄할 사람을 현재 화면 및 담당 안내와 대조합니다.
- **직책·근무지 표기가 애매**하면 실제 선택지와 화면 안내를 먼저 확인합니다. 조직의 직급을 명함 직책으로 자동 변환하지 않습니다.

실제 인쇄할 정보와 신청 대상이 확인되면 작성합니다. 대리 신청에서 신청자 칸에 누구를 선택하는지 불명확하거나 인쇄할 직책·근무지가 화면과 맞지 않으면 그 항목만 먼저 확인합니다. 먼저 초안을 요청했다면 **확인 전 초안**으로 표시하고, 달라질 수 있는 인쇄값은 확인 사항에 남깁니다. 전화번호와 업무용 이메일은 신청자가 원자료로 대조해 직접 입력합니다.

## 작성 화면에 넣기

1. **신청자**에서 본인 또는 실제 명함의 신청 대상자를 선택합니다.
2. **부서**에는 명함에 표시할 팀 이름을 적습니다.
3. **직책**은 명함에 인쇄하도록 확인된 값을 화면에서 고릅니다. 사원·팀장·점장 등 실제 표시되는 선택지와 조직의 명함 표기 기준을 확인합니다.
4. **근무지**는 실제 인쇄할 사업장의 이름을 화면 목록에서 고릅니다. 목록에 원하는 표기가 없으면 담당자에게 확인합니다.
5. **정보** 표에는 이름, 영문이름, 휴대번호, 이메일을 작성자가 입력합니다. 이메일의 주소 종류와 표기는 명함 발급 기준을 확인합니다.

## 가상 입력 예시

가상 중앙점 매장 팀원이 본인 신규 명함을 신청합니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 중앙점 매장운영팀 신규 명함 신청 |
| 신청자 | 본인 선택 |
| 부서 | 매장운영팀 |
| 직책 | 사원 |
| 근무지 | 가상 중앙점 |
| 정보 | 아래 1행 |

| 이름 | 영문이름 | 휴대번호 | 이메일 |
|---|---|---|---|
| [가상 한글 이름] | [가상 영문 이름] | 신청자가 인쇄에 사용할 번호 직접 입력 | 신청자가 본인 업무용 메일 주소 직접 입력 |

**작성자 확인**

영문 이름의 순서와 철자, 전화번호, 이메일을 한 글자씩 대조합니다. 신청자, 직책과 근무지가 실제 인쇄 요청 내용과 맞는지 확인합니다.

## BEST 사례 · 근무지 변경과 대리 신청

가상 매장지원 담당자가 매장운영팀 구성원의 근무지 변경에 맞춰 명함을 준비합니다. 실제 인쇄 대상의 부서와 직책은 확인했으며, 대리 작성 시 **신청자** 칸의 선택 대상은 확인 중입니다.

| 화면 항목 | 가상 입력값·확인 사항 |
|---|---|
| 제목 | 매장운영팀 근무지 변경 명함 신청 |
| 신청자 | 대리 작성 시 선택 기준 확인 필요 |
| 부서 | 매장운영팀 |
| 직책 | 사원 |
| 근무지 | 기존 가상 중앙점에서 가상 동쪽점으로 변경 |
| 정보 | 기존 명함의 한글·영문 이름 표기를 대상자와 대조. 휴대번호와 업무용 이메일은 화면에서 직접 확인해 입력 |

**작성자 확인**　실제 신청 화면에는 **근무지**를 `가상 동쪽점`으로 선택합니다. 대리 작성자와 명함 인쇄 대상이 다른 경우 신청자 선택 기준을 소관 담당에게 확인합니다. 기존 값이 그대로 인쇄되는 항목도 대상자와 최종 대조합니다.
