# 채용 품의 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

인사 담당이 확인한 채용 예정자와 채용 조건을 승인받을 때 사용합니다. 모집 자체를 요청하는 단계는 [채용 요청서](recruitment-request.md)를 확인하세요.

## 작성 전에 준비하기

원채용 요청서, 조건 변경 승인 문서가 있는지 확인합니다. 실제 배치 부서, 직급, 계약 형태, 급여단계, 계약 연봉액의 포함 범위와 입사 예정일을 인사 원자료에서 확인합니다.

### 메모에서 빠진 내용만 확인하기

- **후보자와 조건이 정해진 경우** 승인받을 조건의 범위와 근거를 확인합니다. 채용 여부나 조건은 인사 담당과 작성자가 결정합니다.
- **원요청과 조건이 달라진 경우** 배치, 형태, 인원, 처우, 일정 중 무엇이 달라졌고 변경 승인을 받았는지 확인합니다. 협의 중이면 현재 상태와 확인할 담당을 남깁니다.
- **연봉 자료의 범위가 다른 경우** 식대 포함 여부, 금액 단위, 합의 상태를 먼저 대조합니다. 인사 자료에서 양식이 지정한 포함 범위에 맞는 연봉을 확인합니다.
- **선행 문서나 증빙에 접근할 수 없는 경우** 이미 아는 제목·번호만 남기고 작성자가 직접 확인·연결하도록 표시합니다. 후보자의 개인 정보 전문은 초안에 요청하지 않습니다.

실제 배치와 계약 조건, 승인 요청 범위가 자료로 확인되면 작성합니다. 원요청과 품의의 근무지나 고용형태가 다르면 변경 승인 상태를, 연봉의 식대 포함 여부가 불분명하면 표에 입력할 금액을 먼저 확인합니다. 사용자가 초안을 먼저 요청하면 **확인 전 초안**으로 표시하고, 바뀐 조건과 미확인 값을 본문 및 작성자 확인에 남깁니다. 연봉은 양식의 포함 범위를 확인하고 인사 자료의 해당 금액을 입력합니다.

## 작성 화면에 넣기

1. **연관문서**에 원채용 요청서와 관련 조건 변경 승인 문서를 연결합니다. 접근할 수 없으면 문서 제목·번호와 확인 상태를 채용 사유에 적습니다.
2. **채용 부서**는 화면 목록에서 실제 배치 조직을 선택합니다.
3. **채용 예정자** 표에는 성명, 생년월일, 직급, 근로 계약 형태, 급여단계, 계약 연봉액(양식이 지정한 포함 범위), 입사 예정일, 근무지, 연락처를 입력합니다. 직급·계약 형태·급여 구분·근무지는 실제 화면의 선택지와 확인된 조건을 대조합니다. 표시된 기본값도 합의된 조건과 대조합니다. 개인 정보는 작성자가 원자료를 보면서 직접 입력합니다.
4. **채용 사유**에는 채용을 요청하는 근거, 승인받을 조건, 원요청과 달라진 점을 적습니다. 확인되지 않은 조건에는 협의 또는 확인 상태를 표시합니다.
5. **파일첨부**는 승인에 필요한 자료만 연결합니다. 이력·평가 자료는 열람 범위와 개인정보 가림 여부를 확인합니다.

## 가상 예시

가상 물류운영팀이 승인된 포장 담당 1명 모집을 마치고 인사 담당이 확인한 조건으로 채용 품의를 준비합니다. 인원·부서·고용형태가 원요청과 같은 경우입니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 물류운영팀 포장 담당 1명 채용 품의 |
| 연관문서 | 가상 원채용 요청서 `물류운영팀 포장 담당 정규직 1명 모집 요청`을 작성자가 연결 |
| 채용 부서 | 물류운영팀 |
| 채용 예정자 | 아래 1행 |
| 채용 사유 | 아래 본문 |
| 파일첨부 | 가상 채용 조건 확인 요약. 작성자가 열람 범위와 가림 상태를 확인한 파일을 연결 |

| 성명 | 생년월일 | 직급 | 근로 계약 형태 | 급여단계 | 계약 연봉액(양식이 지정한 포함 범위) | 입사 예정일 | 근무지 | 연락처 |
|---|---|---|---|---|---|---|---|---|
| 작성자가 원자료 대조 후 입력 | 작성자 직접 입력 | 사원 | 정규직 | 신입 | 30,000,000원 | 2026-12-07 | 가상 북쪽 사업장 | 작성자 직접 입력 |

**채용 사유**

> 승인된 포장 담당 모집에 따라 물류운영팀 가상 북쪽 사업장 근무 정규직 사원 1명의 채용을 요청합니다. 인사 담당이 면접 기록에서 포장 목록과 라벨을 대조하고 오류 발견 시 보고하는 절차를 확인했습니다. 인원·배치 부서·고용형태는 원채용 요청 범위와 같습니다. 입사 예정일은 12월 7일이며 계약 조건은 채용 예정자 표와 같습니다.

**작성자 확인**

선행 승인 범위, 계약 조건, 연봉의 단위와 포함 범위, 입사 예정일을 대조합니다. 조건이 바뀌었으면 변경 근거와 승인 상태를 확인합니다. 후보자 정보와 첨부 열람 범위는 작성자가 직접 확인합니다.

## BEST 사례 · 기존 승인과 바뀐 근무지·계약 조건

가상 양식의 연봉 칸은 식대를 제외하는 설정입니다. 가상 원요청은 물류운영팀 가상 북쪽 사업장 근무 정규직 1명 모집을 승인했습니다. 현장 배치 계획이 변경돼 같은 부서의 가상 동쪽 사업장 근무와 계약직을 제안합니다. 조건 변경 승인 기록은 아직 확인되지 않았습니다. 인사 자료는 연간 합계 33,600,000원과 식대 연 2,400,000원을 명시하며, 식대 제외 계약 연봉액은 31,200,000원으로 확인했습니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 물류운영팀 포장 담당 채용 품의 및 근무지·계약 조건 변경 요청 |
| 연관문서 | 가상 북쪽 사업장 정규직 모집 원요청을 연결. 조건 변경 승인 문서는 확인 중 |
| 채용 부서 | 물류운영팀 |
| 채용 예정자 | 사원 · 계약직 · 경력 · 식대 제외 31,200,000원 · 2026-12-14 입사 예정 · 가상 동쪽 사업장. 성명·생년월일·연락처는 화면에서 직접 입력 |
| 채용 사유 | 아래 본문 초안 |
| 파일첨부 | 가상 배치 변경 사유와 조건 대조표. 작성자가 실제 확인 자료 연결 |

**채용 사유 · 확인 전 초안**

> 포장 담당 1명 채용을 검토해 주시기 바랍니다. 원채용 요청서에는 가상 북쪽 사업장 근무 정규직 1명으로 승인돼 있습니다. 이번에는 가상 현장 배치 계획 변경에 따라 같은 부서에서 가상 동쪽 사업장 근무 계약직 1명을 제안합니다. 식대 제외 계약 연봉액은 인사 확인 자료 기준 31,200,000원입니다. 근무지와 계약 형태의 변경 승인 여부와 처리 경로를 확인 중입니다. 변경 조건이 결정된 뒤 입사 안내에 반영합니다.

**작성자 확인**　원요청과 달라진 근무지·계약 형태를 대조하고, 변경과 품의를 같은 문서에서 검토할 수 있는지 인사 담당에게 확인합니다. 실제 계약기간 및 입사 예정일을 원자료와 대조합니다. 승인 범위가 확인되기 전에는 조건 변경이나 채용 확정으로 처리하지 않습니다.
