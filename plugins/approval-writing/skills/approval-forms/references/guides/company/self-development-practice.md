# 자기계발목적 연습 계획 및 동의서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

회사에서 안내한 자기계발 목적의 연습 기회를 이용하려고 계획을 제출할 때 사용합니다. 연습 공간·일정과 화면에 표시된 동의서 전문을 확인합니다.

## 작성 전에 준비하기

연습 목표와 기간, 빈도, 장소, 시작·종료 시간, 연습 방법을 적습니다. 장기 연습은 주요 단계와 시기별 계획을 나눕니다.

| 상황 | 계획을 정리할 질문 |
|---|---|
| 단기 | 기간 안에 연습할 기술이나 주제는 무엇이며, 어떤 기록으로 확인할 수 있나요? 몇 회 정도 할 계획인가요? |
| 장기 | 단계별 목표와 시기는 어떻게 되나요? 단계마다 장소·시간·빈도가 달라지나요? |
| 장소나 시간 협의 중 | 어느 일정·장소가 아직 미정이며, 어떤 범위까지 초안에 쓸 수 있나요? |

기간과 연습 조건이 확인되면 실제 계획으로 초안을 작성합니다. 유형 선택에 필요한 기간이 없거나 여러 장소 중 어느 곳을 이용할지 불명확하면 시작·종료일과 적용 범위부터 확인합니다. 사용자가 확인 전 초안을 요청했다면 **확인 전 초안**으로 표시하고, 장소 사용이나 일정이 협의 중인 부분은 작성자 확인에 둡니다. 동의와 신청자 정보는 본인이 직접 입력합니다.

## 작성 화면에 넣기

1. **동의서 내용** 전문을 읽습니다. **동의 체크**는 신청자가 직접 판단해 선택하고 **동의 날짜**가 실제 날짜와 맞는지 확인합니다.
2. **이름**, **부서/직책**, **연락처**를 신청자가 직접 입력합니다.
3. **연습 유형**에서 조직의 기간 기준과 실제 선택지를 대조합니다. 단기와 장기는 가상 양식의 예시입니다. **연습 목표**에는 연습을 마칠 때 확인할 수 있는 구체적인 목표를 적습니다.
4. **연습 기간**과 **연습 주기**, **연습 장소**, **연습 시간**을 입력합니다. 기간과 반복 빈도를 구분하고, 장소·시간이 시기에 따라 달라지면 나눠 적습니다.
5. **연습 내용**에 실제로 할 활동과 확인 방법을 적습니다. **기대 효과**에는 예상되는 변화가 있으면 적습니다. 입력란의 필수 여부는 실제 화면에서 확인합니다.

## 가상 예시

표준 추출 레시피 재현성을 확인하려는 단기 연습입니다. 사내 교육 공간과 이용 시간은 담당자와 협의했습니다.

| 입력 칸 | 복사·선택할 값 |
|---|---|
| 동의서 내용 | 화면에 표시된 전문을 직접 읽음 |
| 동의 체크 · 동의 날짜 | 신청자가 직접 선택하고 실제 동의 날짜를 확인 |
| 이름 · 부서/직책 · 연락처 | 신청자가 실제 값을 화면에 직접 입력 |
| 연습 유형 | 단기 |
| 연습 목표 | 분쇄도별 차이를 기록해 표준 추출 레시피의 재현성 확인 |
| 연습 기간 | 2026-11-16 ~ 2026-12-11 |
| 연습 주기 | 주 1회 |
| 연습 장소 | 사내 교육 공간(가상) |
| 연습 시간 | 19:00~20:00 |
| 연습 내용 | 동일한 원두와 레시피로 분쇄도를 달리해 추출하고, 회차별 추출 시간과 맛의 차이를 기록합니다. |
| 기대 효과 | 추출 편차가 생겼을 때 확인할 기준을 정리할 수 있을 것으로 기대합니다. |

이 서식의 연습 계획은 각 입력란에 나눠 넣습니다. 장기 연습이라면 **연습 내용**에 기간을 단계로 나누고 단계별 목표를 적습니다. 단계마다 장소와 시간이 달라지면 **연습 장소**와 **연습 시간**에도 그 차이를 적습니다.

**작성자 확인**　유형과 기간, 반복 주기와 이용 장소·시간을 대조합니다. 동의 선택, 동의 날짜와 신청자 정보는 신청자가 직접 확인합니다.

AI에 초안을 요청할 때는 연습 계획과 합의 여부를 알려 주세요. 본인의 동의 선택과 연락처는 화면에서 직접 처리합니다.

## BEST 사례 · 장기 연습의 단계별 일정

가상 신청자는 표준 추출 레시피의 재현성을 점검하기 위해 2026년 12월부터 2027년 2월까지 장기 연습을 계획합니다. 1단계 교육 공간 이용은 협의했고, 2단계 테스트 공간과 시간은 희망 조건입니다.

| 입력 칸 | 가상 입력값·확인 사항 |
|---|---|
| 동의서 내용 · 동의 체크 · 동의 날짜 | 신청자가 화면에서 전문을 읽고 직접 선택·확인 |
| 이름 · 부서/직책 · 연락처 | 신청자가 화면에 직접 입력 |
| 연습 유형 | 장기 |
| 연습 목표 | 조건별 추출 기록을 비교해 레시피 재현성 점검 |
| 연습 기간 | 2026-12-01 ~ 2027-02-28 |
| 연습 주기 | 12월 주 1회, 1~2월 주 2회 계획 |
| 연습 장소 | 12월 사내 교육 공간(가상, 협의 완료). 1~2월 테스트 공간(가상, 협의 필요) |
| 연습 시간 | 12월 19:00~20:00. 1~2월 18:30~19:30 희망, 협의 필요 |
| 연습 내용 | 아래 예시 |
| 기대 효과 | 추출 편차의 원인을 비교할 수 있는 기록 양식을 정리합니다. |

**연습 내용**

> 12월에는 같은 원두에서 분쇄도만 바꾸고 추출 시간과 맛을 기록합니다. 1~2월에는 정한 조건을 반복 적용해 편차를 확인하고, 회차별 기록을 비교해 재현성을 점검합니다. 2단계 장소와 시간은 담당자와 협의한 뒤 적용합니다.

**작성자 확인**　날짜·주기·장소·시간이 단계별 계획과 맞는지 확인합니다. 화면에서 복수 조건을 입력하는 방법과 2단계 이용 가능 여부를 확인합니다. 신청자가 직접 동의 여부와 실제 동의 날짜를 확인합니다.
