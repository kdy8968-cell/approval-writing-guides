# 연장 근무 신청서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

예정 근무시간을 넘겨 수행할 작업에 대해 연장 근무를 신청할 때 사용합니다. 작업 필요성과 예정 시간부터 확인합니다.

## 작성 전에 준비하기

근무 날짜, 시작·종료 시각, 연장 근무 시간과 작업 사유를 준비합니다. 여러 날이면 날짜별 시간과 사유를 적습니다. 휴게시간이나 자정 경과가 있으면 회사의 시간 산정 안내를 확인합니다.

| 상황 | 먼저 확인할 내용 |
|---|---|
| 하루 연장 근무를 신청 | 대상 날짜, 예정 시작·종료 시각, 작업과 연장 필요 사유 |
| 여러 날 또는 날짜별 시간이 다름 | 날짜별 시간과 사유, 시간 범위 하나로 입력 가능한지, 총시간에 포함한 날짜 |
| 휴게·자정 경과가 있음 | 실제로 해당되는 휴게·날짜 경계, 회사 산정 기준과 화면 입력 방법 |
| 이미 일했거나 신청 내용을 고침 | 예정 신청인지 실제 근무 결과 반영·정정인지, 원신청 상태와 담당 안내의 경로 |

일시나 근무 사유가 자료에 있으면 다시 묻지 않습니다. 휴게나 날짜 경계가 총시간에 영향을 주는데 적용 기준을 확인하지 못했다면 총시간을 `확인 필요`로 남깁니다.

근무 날짜·예정 시각·사유가 서로 맞으면 작성합니다. 자정을 넘기는 건이 어느 날에 속하는지, 날짜별 시간이 화면의 한 범위에 들어가는지 불명확하면 해당 입력 방법을 먼저 확인합니다. 사용자가 먼저 초안을 요청하면 **확인 전 초안**으로 표시하고, 확인된 날짜별 시각과 산술 계산을 본문에 적습니다. 실제 입력할 총시간과 적용 기준은 확인 항목에 남깁니다.

## 작성 화면에 넣기

1. **제목**이 표시되면 날짜와 주요 작업을 적습니다.
2. **근무 구분**이 표시되면 실제 화면에서 연장근무에 해당하는 값을 확인합니다.
3. **근무 날짜**에 시작일과 종료일을 입력합니다. 날짜 범위와 필수 여부는 화면에서 확인합니다. 하루만 신청하고 시작일·종료일이 각각 필요하면 같은 날을 입력합니다.
4. **시간(범위)**와 **총 연장근무 시간**에 예정 시작·종료 및 확인된 총시간을 입력합니다. 날짜별 시간이 다르면 **근무 사유**에 내역을 나눠 적고 실제 범위 입력 방법을 화면에서 확인합니다.
5. **근무 사유**에 예정 작업과 정규 근무시간 안에 마치기 어려운 이유를 적습니다.
6. 근거가 되는 작업 일정이나 선행 요청이 있으면 **파일첨부** 또는 **연관문서**로 연결합니다.

## 가상 예시

포장자재가 예정 근무 종료 직전에 도착해 당일 검수와 입고 기록에 두 시간이 필요한 상황입니다. 예시는 해당 두 시간에 별도 휴게가 없다는 설정입니다.

| 입력 칸 | 복사·선택할 값 |
|---|---|
| 제목이 표시되는 경우 | 11월 20일 포장자재 검수 연장 근무 신청 |
| 근무 구분 | 연장 |
| 근무 날짜 | 2026-11-20 – 2026-11-20 |
| 시간(범위) | 18:00–20:00 |
| 총 연장근무 시간 | 2시간 |
| 근무 사유 | 아래 본문 |
| 파일첨부 | 제공된 자료에서 확인되지 않음 |
| 연관문서 | 제공된 자료에서 확인되지 않음 |

**근무 사유**

> 11월 20일 예정 근무 종료 직전에 도착하는 포장자재의 검수와 입고 기록을 당일 마무리하기 위해 18:00–20:00 연장 근무를 신청합니다.

**작성자 확인**　날짜별 시간과 총시간을 대조하고, 휴게·자정 경과가 있으면 실제 산정 기준을 확인합니다. 신청한 시간과 승인·근태 반영 시간은 실제 화면에서 각각 확인합니다.

## BEST 사례 · 날짜별 시간이 다르고 자정을 넘기는 경우

11월 20일 입고 기록을 마감하고 11월 21일 늦은 배송을 검수하려는 예정 신청입니다. 원자료에는 아래 시각과 휴게가 확인됩니다. 화면에서 서로 다른 두 시간 범위와 자정 경계를 어떻게 넣는지는 확인되지 않았습니다.

| 작업 시작일 | 예정 시간 | 기록상 휴게 | 시작부터 종료까지 |
|---|---|---|---|
| 11월 20일 | 18:00–20:00 | 없음 | 2시간 |
| 11월 21일 | 22:30–11월 22일 00:30 | 30분 | 2시간 |

경과 시간은 4시간입니다. 표의 휴게 30분을 단순 차감하면 3시간 30분이며, 실제 신청 시간은 적용 기준을 확인한 뒤 입력합니다. “자정에 걸친 시간의 신청 날짜·휴게 반영 기준과 두 건을 한 문서에 넣는 방법을 확인했나요?”라고 묻습니다.

| 입력 칸 | 확인 전 초안에 표시할 내용 |
|---|---|
| 제목이 표시되는 경우 | 11월 20–21일 입고 기록·배송 검수 연장 근무 신청 |
| 근무 구분 | 연장 |
| 근무 날짜 | 작업 시작일 11월 20일·21일. 화면의 시작일·종료일 입력 기준 확인 필요 |
| 시간(범위) | 날짜별 시각은 위 표 참조. 화면 입력 방법 확인 필요 |
| 총 연장근무 시간 | 확인 필요 |
| 근무 사유 | 11월 20일에는 입고 기록을 마감하기 위해 18:00–20:00에 연장 근무를 신청합니다. 11월 21일에는 늦게 도착하는 배송을 검수하기 위해 22:30부터 11월 22일 00:30까지 신청합니다. 11월 21일 작업의 기록상 휴게는 30분입니다. |
| 파일첨부 | 실제 작업 일정이 있으면 작성자가 연결 |
| 연관문서 | 제공된 자료에서 확인되지 않음 |

**작성자 확인**　화면에서 날짜 경계와 범위 입력 방법을 확인하고, 회사의 휴게 반영 기준과 일치하는 총시간을 입력합니다. 날짜별 시간이 다를 때 시작과 종료를 두 날짜에 걸친 하나의 연속 근무처럼 합치지 않습니다.

AI에 요청할 때는 날짜와 시각, 해야 할 일, 예정 신청인지 실제 근무를 반영하는 일인지를 알려 주세요. 초안은 입력값, 근무 사유, 작성자 확인으로 나눠 받습니다.
