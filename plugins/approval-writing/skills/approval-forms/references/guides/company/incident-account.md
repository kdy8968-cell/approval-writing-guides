# 시말서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

회사 담당자가 시말서 작성을 안내한 사안에 대해 본인이 확인한 경위와 조치를 기록할 때 사용합니다. 경위서와 시말서 중 어느 서식이 필요한지 불명확하면 담당자 안내를 확인합니다.

## 작성 전에 준비하기

발생일자·장소, 당시 맡은 일, 확인된 행동과 영향, 취한 조치, 관련 문서를 준비합니다. 기록으로 대조할 수 있는 항목부터 정리합니다.

### 메모에서 빠진 내용만 확인하기

- **작성 범위가 불명확한 경우** 담당자가 요청한 사건과 본인이 맡은 업무를 확인합니다. 조직의 판단이나 다른 사람의 행동을 본인의 진술로 바꾸지 않습니다.
- **기록과 기억이 다른 경우** 확인한 기록, 본인이 기억하는 내용, 아직 대조하지 못한 부분을 표시합니다. 작성자와 확인하기 전 책임 인정·사과·이행 약속을 초안에 추가하지 않습니다.
- **대책을 적는 경우** 이미 본인이 적용한 점검과 앞으로 적용할 제안 또는 합의를 구분합니다. 본인 권한 밖의 담당·일정은 합의된 경우에만 적습니다.

작성 대상이나 본인의 역할이 불명확하면 담당자의 요청과 당시 맡은 일을 먼저 확인합니다. 확인된 사건과 본인의 조치만으로 범위가 충분하면 원인 조사가 끝날 때까지 기다리지 않고 확인 상태를 적습니다. 기록과 본인 기억이 충돌하고 사용자가 먼저 초안을 원하면 **확인 전 초안**에서 자료별 내용을 표시합니다.

## 작성 화면에 넣기

1. **작성일자**, **소속**, **성명**을 확인합니다. 소속과 성명은 각각 부서·사원 검색으로 선택합니다.
2. **발생일시**와 **발생장소**를 적습니다. 발생일시 칸이 날짜만 받으면 확인된 시각은 본문에 적습니다.
3. **개요**에 사건과 영향을 짧게 적습니다. **경위 및 원인**에는 본인이 직접 확인한 내용, 조치한 시각, 확인이 남은 사항을 정리합니다.
4. **재발 방지 대책**에는 본인이 실제로 적용한 조치와 적용을 협의할 조치를 적습니다.
5. **연관문서**에는 직접 관련된 기존 기록이 있을 때 연결합니다.

## 가상 예시

가상 제품생산팀에서 담당자가 시말서 작성을 안내했습니다. 작성자는 본인이 담당한 점검표의 공란과 발견 후 조치를 정리합니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 작업 확인표 점검 시각 기록 누락 경위 및 조치 |
| 작성일자 | 2026-11-09 |
| 소속 | 제품생산팀 |
| 성명 | 작성자 본인 선택 |
| 발생일시 | 2026-11-06 |
| 발생장소 | 생산 작업장 점검 기록대 |
| 개요 | 제가 담당한 11월 6일 작업 확인표에서 점검 시각 기재란 한 곳이 비어 있음을 확인했습니다. |
| 경위 및 원인 | 11월 6일 17시 작업 확인표를 검토하며 공란을 발견했고, 17시 10분 담당자에게 공유했습니다. 당시 작업 기록을 대조했으나 공란이 생긴 시각과 과정은 확인 중입니다. |
| 재발 방지 대책 | 발견 후 해당 일자 원기록을 따로 표시해 담당자와 대조했습니다. 다음 근무부터 작업을 마치기 전에 점검 시각 기재 여부를 확인하는 방법을 담당자와 협의하겠습니다. |
| 연관문서 | 가상 작업 확인표 누락 공유 기록. 실제 관련 기록이 있으면 작성자가 연결합니다. |

**작성자 확인**

발견 시각과 공유 기록, 이미 수행한 조치를 대조합니다. 책임에 대한 진술과 이행 약속은 본인이 확인한 문구로 작성합니다.

## BEST 사례 · 본인 기억과 기록이 다른 경우

작성자는 11월 6일 16시쯤 점검표에 시간을 적었다고 기억합니다. 같은 날 17시 확인표를 봤을 때 해당 란이 비어 있었고, 17시 10분 이를 담당자에게 공유했습니다. 인계 전 복사본은 아직 확인하지 못했습니다.

“기재했다고 기억하는 문서가 당시 원본과 같은지, 인계 전 복사본이나 수정 이력을 확인할 수 있는지”를 먼저 확인합니다. 답을 기다리는 중에 본문이 필요하면 확인한 범위에서 아래처럼 적습니다.

| 화면 항목 | 확인 전 초안에서 적을 내용 |
|---|---|
| 개요 | 제가 담당한 작업 확인표를 검토하다 11월 6일 점검 시각란이 비어 있음을 확인했습니다. |
| 경위 및 원인 | 저는 같은 날 16시쯤 점검 시각을 적었다고 기억합니다. 17시에 확인한 점검표에는 해당 값이 없었고, 17시 10분 담당자에게 공유했습니다. 당시 작성본과 확인한 문서가 같은지 확인 중입니다. |
| 재발 방지 대책 | 확인표와 당시 작업 기록을 담당자와 대조하고 있습니다. 기재 내용을 인계 전에 확인하는 절차는 대조 결과를 바탕으로 협의하겠습니다. |
| 연관문서 | 확인에 사용한 점검표와 보고 기록이 실제로 등록돼 있으면 작성자가 연결합니다. |

**작성자 확인**　본인 기억과 문서 기록의 차이를 직접 검토합니다. 책임, 사과, 재발 방지 약속에 관한 표현은 본인이 확인한 범위에서 사용합니다.
