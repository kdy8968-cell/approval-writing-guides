# 채용 요청서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

모집할 자리와 조건을 검토받을 때 사용합니다. 후보자와 채용 조건을 정해 승인을 받을 단계라면 [채용 품의](hiring-approval.md)를 확인하세요. 아래 사례는 작성 흐름을 보여 주는 가상 예시입니다.

## 작성 전에 준비하기

직무, 실제 배치 부서, 필요 인원, 채용 형태, 모집 사유와 필요한 시점부터 확인합니다. 사용자 메모와 이미 입력한 값에서 답을 찾고, 작성 결과에 영향을 주는 누락·충돌만 한 번에 묶어 묻습니다. 이미 아는 정보는 다시 묻지 않습니다.

| 상황 | 우선 확인할 내용 |
|---|---|
| 결원 대체·증원·기간 한정 | 기존 인력으로 대응하기 어려운 업무와 인원 근거를 확인합니다. 개인의 퇴사·건강 등 민감한 사유는 제외합니다. |
| 한 부서의 여러 직무·근무지 | 실제 배치 조직 한 곳과 자리별 인원·조건을 확인합니다. 여러 부서이거나 고용형태가 다르면 요청 범위와 화면에서 선택할 값을 작성자에게 확인합니다. |
| 입사 희망일과 업무 시작일이 다름 | 공고 시작·마감, 입사 희망일, 교육, 인계, 실제 투입일을 필요한 만큼 확인합니다. 희망과 확정 일정을 구분합니다. |
| ‘수습 3개월’, ‘3개월 인턴’처럼 기간의 뜻이 불명확 | 그 기간이 교육·적응인지, 평가인지, 전체 계약기간인지 확인합니다. 계약 종료일과 전환 조건은 인사 담당이 확인한 자료를 기준으로 씁니다. |
| 인원 계획·인건비·모집 경로 등이 미정 | 이미 승인된 인원 계획과 인건비 예산을 각각 확인합니다. 이번에 결정받을 조건은 판단 사항으로 남기고, 정보가 아직 없으면 확인 필요로 표시합니다. |
| 공고·선발·오퍼·근무가 이미 진행됨 | 실제로 진행한 단계와 날짜를 확인한 뒤 이번 요청에서 남은 결정을 정리합니다. |

직무·형태·인원·시점·요청 범위가 빠지거나 자료가 충돌하면 핵심 질문에 답을 받은 뒤 완성합니다. 사용자가 먼저 초안을 요청하면 본문 밖에 **확인 전 초안**으로 표시합니다. 지원자 개인정보와 기존 직원의 민감한 사유를 받지 않습니다. 근무 요일·시간, 예산, 자격요건과 모집 담당은 확인된 자료에서 가져오며 협의 중인 값은 표시합니다.

| 확인 상태 | 초안 처리 |
|---|---|
| 공고 기간, 직무·부서·형태·인원, 요청 범위가 서로 맞음 | 제공된 값으로 작성합니다. 현재 승인이나 협의 상태를 그대로 표시합니다. |
| 총인원과 자리별 합계가 다르거나 하나의 모집 부서·형태로 선택할 수 없음 | 어떤 값과 제출 범위가 맞는지 묻습니다. 숫자나 유형을 맞추기 위해 자리별 내역을 조정하지 않습니다. |
| 핵심 값이 빠졌고 먼저 초안을 요청함 | 확인된 입력값과 본문만 제공하고, 날짜·선택값은 실제 화면에서 확인할 항목으로 둡니다. |
| 이번에 근무조건·예산 등의 결정을 요청함 | 기존 인원 계획과 인건비 예산의 확인 상태를 각각 적습니다. 결정받을 범위를 본문 4절에 씁니다. |

## 작성 화면에 넣기

1. **제목**에 직무, 고용형태, 인원, 모집 사유를 한 줄로 적습니다. 근무지가 구분에 필요할 때만 제목에 넣습니다.
2. **채용 배경**에 결원 대체·증원·기간 한정 등 실제 모집 이유와 업무 공백을 짧게 적습니다.
3. **모집 부서**는 부서 검색에서 실제 배치 조직 한 곳을 선택합니다. 작성자 소속이 자동으로 표시되면 실제 배치 부서와 같은지 확인합니다. 조직명을 확인할 수 없다면 선택 후보로 표시합니다.
4. **채용 형태**는 화면에 표시되는 선택지 중 확인한 값으로 설정합니다. 정규직, 전환형 인턴, 기타·협의 필요 등은 예시입니다. 적절한 선택지가 없거나 협의 중이면 희망 형태와 확인할 점을 세부 내용에 적습니다.
5. **채용 인원** 숫자 칸에는 양의 정수만 넣습니다. 제목에는 `1명`처럼 단위를 붙이고, 여러 직무는 자리별 합계를 총인원과 대조합니다.
6. **모집 일정**에 공고 시작일과 지원 마감일을 각각 입력합니다. 날짜가 미정이면 확인 사항에 남깁니다.
7. **세부 내용**을 아래 네 절 순서로 작성합니다. 해당되는 **파일첨부**, **연관문서**는 화면에서 직접 연결합니다.

### 세부 내용에 적을 네 절

| 절 | 작성할 내용 |
|---|---|
| 1. 맡길 업무와 지원 요건 | 모집 직무와 핵심 업무, 확인된 필수 요건과 해당되는 우대 요건 |
| 2. 합류 시점과 근무 조건 | 입사 희망일, 교육 기간, 업무 인계 기간, 입사일과 다른 업무 투입 필요일, 근무 요일과 시간, 배치 부서와 다른 실제 근무 장소, 기간제일 때의 전체 계약기간 |
| 3. 모집·선발 운영 | 희망 모집 경로, 공고 게시 담당, 지원서 접수 담당, 면접 참여 담당, 사전 협의 내용 |
| 4. 승인받을 내용 | 이미 승인된 인원 계획, 이미 승인된 인건비 예산, 이번에 승인받을 내용 |

상단의 채용 배경·부서·형태·총인원·모집 기간은 본문에서 반복을 줄입니다. 같은 부서의 여러 직무는 자리별 인원과 달라지는 조건을 적습니다. 여러 조건의 가로 비교가 필요하면 최대 5열을 기본으로 하고, 상단에서 확인할 공통값과 합계 행은 생략합니다. 해당하지 않는 선택 항목은 뺄 수 있습니다. 확인하지 못한 값과 결재자가 결정할 조건은 각각 상태를 표시합니다.

### HTML과 Editor에 붙여넣기

AI는 **가. 입력 칸**에 제목·채용 배경·채용 인원의 개별 복사값, 부서 검색어와 선택 후보, 고용형태 선택값, 모집 시작일·마감일을 제공합니다. **나. 본문 HTML**은 네 절의 내용만 한 코드블록에 담습니다. **다. 작성자 확인**에는 남은 확인·첨부 연결·협의 사항만 적습니다.

본문은 Sans Serif 14px, 절 제목은 굵게 16px, 왼쪽 정렬, 글자색 `#30343B`, 행간 `1.7`을 사용합니다. 절 앞 16px, 절 제목 뒤 8px, 항목 뒤 4px로 둡니다. 인라인 스타일과 `div`, `p`, `strong`, `br`, 필요한 표 태그를 사용합니다. 이 예시의 직무별 비교표는 `width:100%;border-collapse:collapse;table-layout:auto;`를 기본으로 하고, 셀에 `border:1px solid #D1D5DB;padding:8px;text-align:left;vertical-align:top;font-size:14px;overflow-wrap:anywhere;`를 적용합니다. 고정 폭·높이와 셀 병합은 사용하지 않습니다.

**세부 내용 → HTML** 탭에 코드블록 안의 HTML만 붙여 넣습니다. 이미 작성한 내용이 있다면 최종 초안에 포함됐는지 대조하고, **Editor**로 돌아와 인원·일정·절 순서·줄바꿈을 확인합니다. HTML 사용이 어렵다면 “확인한 내용과 항목 순서를 유지해서 세부 내용의 Editor에 바로 붙여 넣을 본문으로 바꿔 주세요.”라고 요청합니다.

## AI로 초안 요청하기

아래 코드블록의 **복사** 버튼을 누르고, 회사에서 허용한 AI의 새 대화에 붙여 넣습니다. 대괄호에 아는 내용을 채웁니다. 플러그인을 설치했다면 `$approval-forms 채용 요청서로 작성해 주세요`와 업무 메모만 입력해도 됩니다.

```text
네이버웍스 채용 요청서 초안을 작성해 주세요.
이미 제공한 값은 다시 묻지 말고, 서식 선택이나 결정에 필요한 누락·충돌만 묶어 확인해 주세요. 이미 후보자와 채용 조건이 정해진 단계라면 채용 품의가 필요한지 확인해 주세요.

직무, 실제 배치 부서·근무지, 필요 인원, 채용 형태: [확인한 값]
모집 이유와 업무 공백: [결원 대체, 증원, 기간 한정 등과 근거]
공고 시작일과 지원 마감일: [확인한 날짜]
입사 희망일, 교육 기간, 업무 인계 기간, 업무 투입 필요일: [확인한 날짜]
핵심 업무와 요건, 근무 요일과 시간, 희망 계약기간: [확인한 값]
모집 경로, 공고·접수·면접 역할, 협의 상태: [확인한 값]
이미 승인된 인원 계획, 인건비 예산, 이번 결정 요청: [확인한 내용]
직접 연결할 파일과 연관문서: [자료명 또는 확인 상태]

가. 화면 입력값 — 제목, 채용 배경, 실제 배치 부서 한 곳, 채용 형태(정규직·전환형 인턴·기타·협의 필요), 총인원(정수), 공고 시작일·지원 마감일을 각각 주세요. 직무별 인원 합계를 대조하고 공고 기간과 입사·계약 일정을 구분해 주세요.
나. 세부 내용 — 맡길 업무와 지원 요건, 합류 시점과 근무 조건, 모집·선발 운영, 승인받을 내용 순서로 작성해 주세요. 상단 입력값은 필요한 경우에만 다시 언급하고, 기존 승인과 이번 요청 및 협의 중인 조건을 구분해 주세요. 본문만 HTML 코드블록 하나에 담아 주세요. Sans Serif 본문 14px, 굵은 소제목 16px, 행간 1.7을 적용하고, 주제가 바뀌면 문단을 나눠 주세요.
다. 작성자 확인 — 미확인 항목과 직접 연결할 첨부·연관문서를 표시해 주세요. 확인되지 않은 예산·일정이나 개인의 퇴사·건강 사유는 만들어 넣지 마세요.
```

## BEST 사례 2 · 같은 부서의 제빵과 제품 포장 모집

**가상 상황**　매장지원파트가 식품제조팀의 제빵 2명과 제품 포장 1명 모집을 대신 작성합니다. 한 요청으로 작성할 범위와 공통 고용형태를 먼저 확인합니다. 아래 구조 예시는 공통 고용형태를 정규직으로 가정하며, 확인되지 않은 날짜와 근무지는 입력하지 않습니다.

**확인 전 초안**　먼저 “상단 채용 인원은 제빵 2명과 제품 포장 1명을 더한 총 3명인가요? 공고 시작·마감일과 이번에 승인받을 범위는 무엇인가요?”라고 묻습니다. 한 건으로 제출할 범위와 공통 형태가 확인되면 아래 값을 사용할 수 있습니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 제빵·제품 포장 정규직 총 3명 모집 요청 — 자리별 충원 |
| 채용 배경 | 직무별로 발생한 업무 공백과 충원 필요를 확인한 뒤 입력 |
| 모집 부서 | 식품제조팀 한 곳 검색·선택 |
| 채용 형태 | 정규직 |
| 채용 인원 | 3 |
| 모집 일정 | 시작일과 마감일 확인 필요 |

**세부 내용에 들어갈 직무별 내역**

| 직무 | 자리별 인원 | 입사 희망일 |
|---|---:|---|
| 제빵 | 2명 | 협의 필요 |
| 제품 포장 | 1명 | 협의 필요 |

업무·요건·근무지·일정이 실제로 다르면 관련 절에서 직무별로 적습니다. 가상 자료에는 날짜와 채용 배경의 상세 근거가 부족하므로, 입력을 마치기 전에 확인합니다.

| 세부 내용 절 | 이 사례에서 쓸 수 있는 값 |
|---|---|
| 1. 맡길 업무와 지원 요건 | 위 표에서 제빵과 제품 포장 인원을 나눕니다. 구체 업무와 필수·우대 요건은 확인이 필요합니다. |
| 2. 합류 시점과 근무 조건 | 공통 고용형태는 정규직으로 가정한 상태입니다. 직무별 근무지, 희망 입사일, 교육과 근무 조건을 확인합니다. |
| 3. 모집·선발 운영 | 공고 경로와 게시·접수·면접 역할에 대한 자료가 없습니다. |
| 4. 승인받을 내용 | 식품제조팀 내 두 직무의 모집 요청 범위와 기존 인원 계획·인건비 예산 적용 여부를 확인합니다. |

**작성자 확인**　부서 선택이 식품제조팀인지, 총인원 3명과 직무별 2명·1명이 맞는지 확인합니다. 예를 들어 상단 숫자 칸에 2명이 적혀 있으면 어느 값이 맞는지 작성자에게 확인합니다. 공고 날짜, 직무별 업무와 조건, 이번에 승인받을 범위를 확인합니다.
