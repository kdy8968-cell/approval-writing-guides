# 경위서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

업무 중 발생한 일의 경위와 조치를 시간순으로 남길 때 사용합니다. 담당자가 특정 서식을 지정했다면 해당 작성 화면을 엽니다.

## 작성 전에 준비하기

발생일시·장소, 발견 시점, 관련 기록, 확인된 영향과 즉시 조치를 모읍니다. 직접 확인한 일과 전달받은 내용을 각각 표시합니다.

### 메모에서 빠진 내용만 확인하기

- **발생 시점과 발견 시점이 다른 경우** 각각의 근거가 무엇인지 확인합니다. 발생 시점을 모르면 발견 시각만 확정해 적습니다.
- **원인 또는 영향이 확인 중인 경우** 작업 목록·기록 등 확인한 자료와 다음에 대조할 자료를 구분합니다. 관찰한 정황을 원인이나 책임으로 확정하지 않습니다.
- **조치가 여러 단계인 경우** 이미 실행한 조치, 합의한 다음 조치와 제안 단계의 대책을 구분합니다. 담당과 예정일은 합의하거나 확인한 값만 사용합니다.
- **양식 지정이 있는 경우** 담당자가 지정한 경위서, 시말서 또는 해당 업무의 전용 서식으로 작성합니다. 지정이 불명확하고 서식 선택에 영향을 주면 담당 안내를 확인합니다.

발생일과 작성자가 대조한 사건 범위가 모호하거나 출고 여부처럼 영향이 달라지는 값이 충돌하면 그 항목을 먼저 확인합니다. 어떤 사건인지와 즉시 조치가 확인됐다면 정확한 발생 시각이나 원인이 미정이어도 확인된 경위는 작성할 수 있습니다. 자료가 충돌하는 상태에서 먼저 작성을 요청받으면 **확인 전 초안**으로 표시하고 두 기록을 출처와 함께 남깁니다.

## 작성 화면에 넣기

1. **작성일자**, **소속**, **성명**을 작성자 기준으로 확인합니다.
2. **발생일시**, **발생장소**에 확인된 값을 넣습니다. 발생 시각과 발견 시각이 다르면 개요나 경위에 두 시점을 표시합니다.
3. **개요**에는 무엇이 발생했고 어디에 영향이 있었는지 한두 문장으로 적습니다.
4. **경위 및 원인**에는 발생·발견·보고·대응 순서로 적습니다. 원인 확인이 진행 중이면 확인된 사실과 남은 조사를 나눠 적습니다.
5. **재발 방지 대책**에는 이미 시행한 조치와 앞으로 제안하거나 합의한 조치를 구분해 적습니다.

## 가상 예시

가상 물류운영팀에서 출고 전 상자 1개의 라벨 불일치를 발견했습니다. 검수 기록과 작업 목록에서 확인한 내용으로 작성합니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 출고 검수 중 상자 라벨 불일치 경위 |
| 작성일자 | 2026-11-06 |
| 소속 | 물류운영팀 |
| 성명 | 작성자 본인 선택 |
| 발생일시 | 비움. 발생 시점은 확인 중이며 발견 시점은 경위에 적습니다. |
| 발생장소 | 가상 북쪽 사업장 출고 검수대 |
| 개요 | 출고 검수 중 품목 라벨과 작업 목록이 다른 상자 1개를 발견했습니다. 해당 상자는 출고 전 분리했습니다. |
| 경위 및 원인 | 11월 6일 14시 작업 목록과 상자 라벨의 품목이 다른 것을 확인했습니다. 14시 5분 상자를 분리하고 검수 담당에게 알렸습니다. 검수 기록상 해당 상자는 출고 전 보류 상태입니다. 라벨 불일치 발생 시각과 원인은 확인 중입니다. |
| 재발 방지 대책 | 상자 1개를 보류 구역에 두었습니다. 검수 담당이 당일 라벨 발행 기록과 포장 기록을 대조하기로 했습니다. 대조 결과를 바탕으로 추가 확인 절차를 협의합니다. |

**작성자 확인**

발견 시각과 수량, 출고 보류 상태를 기록과 대조합니다. 다른 사람의 진술을 옮길 때는 전달받은 내용임을 표시합니다. 원인과 후속 확인 결과는 확인한 뒤 갱신합니다.

## BEST 사례 · 보류 처리와 출고 목록이 충돌하는 경우

포장 담당은 상자 2개를 분리했다고 전달했습니다. 검수 담당이 직접 확인한 상자는 1개입니다. 출고 목록에는 불일치가 의심되는 품목 1건이 출고 처리로 표시돼 있습니다. 목록의 행이 해당 상자와 같은 건인지는 확인되지 않았습니다.

출고 여부는 영향 범위를 바꾸므로 “출고 목록의 행과 분리 상자가 같은 건인지, 실제 인계 기록에서 확인되나요?”를 먼저 묻습니다. 먼저 초안이 필요하면 아래처럼 확정할 수 있는 사실과 대조할 기록을 작성합니다.

| 화면 항목 | 확인 전 초안에서 적을 내용 |
|---|---|
| 개요 | 검수대에서 라벨 불일치 상자 1개를 직접 확인했습니다. 추가 상자 수량과 출고 영향은 확인 중입니다. |
| 경위 및 원인 | 포장 담당은 상자 2개를 분리했다고 전달했습니다. 검수 담당은 상자 1개를 확인했습니다. 출고 목록에 해당 품목으로 보이는 처리 행이 있어 상자 식별값과 인계 기록을 대조하고 있습니다. 라벨이 달라진 원인은 확인 중입니다. |
| 재발 방지 대책 | 직접 확인한 상자 1개는 분리했습니다. 추가 상자와 출고 목록의 일치 여부를 확인한 뒤 필요한 조치를 협의합니다. |

**작성자 확인**　두 기록의 수량과 상자 식별값을 대조하고 확인한 출고 상태를 반영합니다. 실제 조회 전에는 출고 여부나 전체 영향 수량을 확정하지 않습니다.
