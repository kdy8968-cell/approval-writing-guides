# 소비자 클레임 발생서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

제품이나 서비스에 대한 개별 고객 클레임이 발생해 초기 확인과 대응을 공유할 때 사용합니다. 즉시 조치가 필요한 문제는 회사의 대응·보고 절차를 먼저 따릅니다.

## 작성 전에 준비하기

접수 일시·채널, 제품이나 서비스, 고객이 알린 증상, 직접 확인한 사실, 즉시 조치와 아직 확인할 내용을 모읍니다. 관련 사진·동영상·영수증이 있으면 문제 확인에 필요한 부분을 준비합니다.

| 상황 | 내용이 부족할 때 확인할 질문 | 본문에서 구분할 사실 |
|---|---|---|
| 최초 접수 | 언제 어떤 채널에서 접수했고 고객이 어떤 현상을 알렸나요? | 발생 시점, 접수 시점, 고객이 설명한 내용 |
| 증빙이나 현장 확인 | 사진·제품·거래 기록 중 무엇을 직접 확인했나요? | 실제 관찰 사실과 확인 중인 원인·범위 |
| 고객 응대 또는 후속 조치 | 이미 안내하거나 실행한 조치가 있나요? 다음 확인 담당과 일정은 합의됐나요? | 안내·실행·제안·미정 상태 |

복수 문의의 공통 의견과 개선 현황을 집계해 공유하는 목적이면 [VOC 리포트](voc-report.md)를 검토합니다. 긴급 조치가 필요한 문제라면 실제 담당 경로를 사용합니다.

접수 대상과 고객에게 이미 안내한 조치가 확인되면 원인 조사가 진행 중이어도 초기 보고를 작성합니다. 증빙이 같은 건인지, 대응이 안내 단계인지 실행됐는지에 따라 후속 조치가 달라지면 해당 기록을 먼저 확인합니다. 먼저 공유할 초안이 필요하면 **확인 전 초안**으로 표시하고, 고객 설명과 직접 확인한 내용을 출처별로 적습니다.

## 작성 화면에 넣기

1. **스마트 에디터**에 접수·발생 시점, 접수 채널, 대상, 고객이 알린 문제를 먼저 적습니다.
2. 같은 본문에 직접 확인한 사실, 고객에게 안내했거나 현장에서 수행한 조치, 남은 확인과 담당을 적습니다. 고객 진술과 조사 결과를 구분합니다.
3. **첨부자료**에 문제 확인에 도움이 되는 사진·동영상·영수증을 연결합니다. 고객 식별 정보는 필요한 범위만 남깁니다.
4. **연관문서**에 관련 선행 보고나 대응 기록이 있으면 연결합니다.

## 완성 예시 · 가상 외포장 파손 접수

| 입력 칸 | 작성값 |
|---|---|
| 제목 | 제품 외포장 파손 접수 및 초기 대응 |
| 첨부자료 | 외포장 사진 1장, 작성자가 식별 정보 확인 후 첨부 예정 |
| 연관문서 | 없음 |

**스마트 에디터**

> **접수 및 확인 내용**
>
> 11월 6일 온라인 문의로 제품 외포장 파손 신고 1건을 접수했습니다. 고객이 제공한 사진에서 외포장 모서리의 눌림을 확인했습니다. 파손 시점과 제품 자체의 상태는 확인 중입니다.
>
> **조치와 남은 확인**
>
> 고객에게 문의가 접수됐음을 안내했습니다. 담당자가 포장·배송 기록을 대조한 뒤 교환 가능 여부를 확인할 예정입니다. 결과 안내 시점은 미정입니다.

**작성자 확인**　사진이 해당 건의 증빙인지, 첨부에 고객 식별 정보가 포함되어 있는지, 안내한 내용과 실제 조치가 기록과 일치하는지 확인합니다.

## BEST 사례 · 고객 설명과 사진 확인 범위가 다른 경우

11월 9일 온라인 문의로 고객이 상품 2개 모두 외포장이 찢어졌다고 알렸습니다. 전달받은 사진에는 상자 1개가 보입니다. 상담 기록에는 “교환 가능 여부 확인 후 다시 안내”만 있습니다. 추가 사진과 주문 내역이 같은 접수 건에 속하는지 대조 중입니다.

교환이나 회수 단계가 이어지기 전에 “사진이 이 주문의 어느 상품인지, 사진이 없는 상품 상태를 확인했는지, 교환이나 회수 절차를 실제로 진행했는지”를 확인합니다. 답을 기다리는 중에도 접수 및 안내 기록을 바탕으로 초기 공유 초안을 쓸 수 있습니다.

| 입력 칸 | 확인 전 초안에 표시할 내용 |
|---|---|
| 제목 | 온라인 외포장 파손 문의 접수 및 확인 현황 |
| 스마트 에디터 | 아래 본문 |
| 첨부자료 | 사진 1장. 작성자가 접수 건과의 일치 여부 및 식별 정보 표시를 확인한 뒤 연결 |
| 연관문서 | 관련 상담 기록이 실제 등록돼 있으면 작성자가 연결 |

**스마트 에디터**

> **접수와 확인 범위**
>
> 11월 9일 온라인 문의로 상품 2개의 외포장에 찢김이 있다는 고객 설명을 접수했습니다. 전달받은 사진에는 찢김이 보이는 외포장 1개가 있으며 주문 상품과 대조 중입니다. 두 번째 상품의 상태, 내용물 상태, 파손 시점과 원인은 확인 중입니다.
>
> **응대와 후속 확인**
>
> 상담 기록상 교환 가능 여부를 확인해 다시 안내하겠다고 전달했습니다. 포장·배송 기록과 사진을 대조한 뒤 조치 범위와 안내 일정을 확인합니다.

**작성자 확인**　상품 수량과 사진·주문 내역을 대조합니다. 교환·회수나 추가 안내가 진행됐다면 실제 기록을 확인한 뒤 반영합니다. 첨부의 열람 범위와 식별 정보 표시를 확인합니다.
