# 근무시간 변경 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

예정된 근무의 시작 또는 종료 시간을 조정해 달라고 신청할 때 사용합니다. 일시 변경인지 특정 기간에 반복 적용할 변경인지 먼저 확인합니다. 반복 변경을 한 건으로 신청할 수 있는지는 실제 작성 화면과 담당 안내에서 확인합니다.

## 작성 전에 준비하기

대상 날짜나 적용 기간, 기존 근무시간과 변경 희망 시간, 변경 사유를 정리합니다. 휴게시간이나 대체 근무가 바뀌면 그 내용과 협의 상태를 확인합니다.

| 상황 | 먼저 확인할 내용 |
|---|---|
| 특정일만 변경 | 대상 날짜, 기존 시각과 변경 희망 시각, 변경 사유 |
| 여러 날에 적용 | 적용 시작일·종료일, 해당 요일이나 날짜, 요일별 변경 시간 |
| 이미 근무한 기록을 정정 | 실제 근무일과 시각, 기존 기록과 달라진 이유, 담당 안내의 신청 경로. 실제 근무 결과를 반영하는 업무라면 [근무 결과 신청](../system/work-result-request.md)을 확인합니다. |

기존 시간과 변경 희망 시간이 없거나 적용 범위가 불명확하면 그 값만 확인합니다. 인계나 대체 근무가 미정이면 담당·협의가 남아 있다고 표시합니다.

변경 전후 시각과 대상 날짜가 일치하면 초안을 작성합니다. 요청 기간과 근무표가 다르거나 요일 표현으로 날짜를 특정할 수 없으면 포함할 날짜와 근무표 기준을 먼저 묻습니다. 사용자가 확인 전에 초안을 원하면 **확인 전 초안**으로 표시하고, 확인된 날짜만 본문에 적습니다.

## 작성 화면에 넣기

1. **제목**이 표시되면 대상 날짜 또는 적용 기간과 변경 내용을 한 줄로 적습니다.
2. **사유입력** 첫 줄에 적용 날짜와 변경 전후 시간을 적습니다. 여러 날을 변경하면 같은 시간이 적용되는 날짜끼리 묶어 적습니다.
3. 같은 본문에 변경 사유와 업무 공백을 어떻게 처리할지 적습니다. 이미 협의한 내용과 협의가 필요한 내용을 구분합니다.
4. **파일첨부**에 변경 전후를 비교할 근무표가 있으면 연결합니다.
5. **연관문서**에 연결할 원근무 일정이나 선행 승인 문서가 있을 때 등록합니다.

## 가상 예시

한 차례 입고 일정이 늦춰졌으며, 시작과 종료를 한 시간씩 늦추는 변경을 요청합니다. 인계 시간은 아직 협의하지 않았습니다.

| 입력 칸 | 복사·선택할 값 |
|---|---|
| 제목이 표시되는 경우 | 11월 20일 근무시간 변경 요청 |
| 사유입력 | 아래 본문 |
| 파일첨부 | 제공된 자료에서 확인되지 않음 |
| 연관문서 | 제공된 자료에서 확인되지 않음 |

**사유입력**

> 11월 20일 근무시간을 09:00–18:00에서 10:00–19:00로 변경 요청드립니다. 같은 날 입고 확인 일정이 늦춰져 시작과 종료를 각각 한 시간씩 늦추려는 건입니다. 인계 시간은 담당자와 확인하겠습니다.

**작성자 확인**　날짜와 변경 전후 시각, 휴게·인계 영향과 실제 협의 상태를 대조합니다. 승인 후 근무표 반영이 필요한 경우 실제 반영 여부를 화면에서 확인합니다.

## BEST 사례 · 반복 변경에 예외 날짜가 있는 경우

11월 23일부터 12월 4일까지 입고 일정에 맞춰 근무를 늦추려는 요청입니다. 메모에는 “월·수·금”이라고 적혀 있으나 11월 27일 입고는 취소됐고 12월 2일은 종료 시각이 다릅니다.

먼저 “입고가 취소된 11월 27일은 변경에서 제외하나요? 12월 2일의 변경 시작·종료 시각은 무엇인가요?”를 확인합니다. 가상 답변은 11월 27일 제외, 12월 2일 11:00–20:00입니다. 기존 근무는 대상일 모두 09:00–18:00이며, 인계 시간은 협의 중입니다.

| 입력 칸 | 작성값 |
|---|---|
| 제목이 표시되는 경우 | 11월 23일–12월 4일 입고 대응 근무시간 변경 요청 |
| 사유입력 | 아래 본문 |
| 파일첨부 | 가상 변경 전후 근무표. 작성자가 실제 파일 연결 |
| 연관문서 | 제공된 자료에서 확인되지 않음 |

**사유입력**

> 입고 예정 시각에 맞춰 아래 날짜의 근무시간을 변경해 달라고 요청드립니다. 11월 27일은 입고가 취소돼 변경 범위에서 제외했습니다. 인계 시간과 휴게 변경 여부는 담당자와 확인 중입니다.

| 적용 날짜 | 변경 전 | 변경 희망 |
|---|---|---|
| 11월 23일·25일·30일, 12월 4일 | 09:00–18:00 | 10:00–19:00 |
| 12월 2일 | 09:00–18:00 | 11:00–20:00 |

**작성자 확인**　월·수·금이라는 표현과 실제 대상일을 대조합니다. 제외일과 예외 시각, 휴게·인계 변경 여부를 확인합니다. 실제 승인 및 근무표 반영 상태는 해당 화면에서 확인합니다.

AI에 요청할 때는 기존 시간과 변경 희망 시간, 적용 범위와 사유를 알려 주세요. 초안은 입력값, 사유입력 본문, 작성자 확인으로 나눠 받습니다.
