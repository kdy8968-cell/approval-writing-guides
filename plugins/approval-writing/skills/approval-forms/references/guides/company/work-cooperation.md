# 업무 협조 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

다른 부서가 자료를 확인하거나 작업을 수행해야 할 때 사용합니다. 상대 부서가 무엇을 언제까지 어떤 형식으로 주면 되는지 정리해 두세요.

## 작성 전에 준비하기

협조를 받을 부서, 요청 배경, 받을 결과물, 희망 기한과 회신 경로를 적습니다. 상대 부서가 참고할 목록, 대상 기간, 양식이나 예시가 있으면 준비합니다.

| 요청 종류 | 내용이 부족할 때 확인할 질문 | 작성할 항목 |
|---|---|---|
| 자료 조회·회신 | 어떤 기간·품목·항목을 어떤 형식으로 받나요? | 대상과 기준일, 회신 필드, 기한과 경로 |
| 작업 지원 | 누가 어떤 작업을 완료하면 되나요? 필요한 선행 자료나 접근 권한이 있나요? | 작업 범위, 시작 조건, 완료 확인 방법 |
| 일정 협의 | 희망 일정인가요, 이미 합의한 일정인가요? | 희망일 또는 합의일과 회신이 필요한 항목 |

협조받을 행동이 여러 개면 각 행동과 산출물을 대응시킵니다. 일정이 결과에 영향이 있을 때만 그 사유를 적습니다. 별도의 결정을 요청하는 경우 [업무 기안](work-proposal.md)의 기준을 확인합니다.

받는 부서, 행동, 결과물과 시점이 확인되면 바로 작성합니다. “데이터 정리 부탁”처럼 상대가 무엇을 제출해야 할지 알 수 없으면 대상 자료·회신 필드·범위를 먼저 묻습니다. 합의된 일정이 없어도 희망 기한으로 작성할 수 있습니다. 중요한 범위가 미확인이고 사용자가 초안을 원하면 **확인 전 초안**으로 표시하고, 확인된 요청과 남은 질문을 작성자 확인에 둡니다.

## 작성 화면에 넣기

1. **제목**에 요청할 일을 적습니다. 예를 들어 `포장자재 품목별 실물 재고 확인 요청`으로 적습니다.
2. **기안 내용**에 협조 부서, 대상 범위, 해야 할 일, 희망 기한과 회신 경로를 적습니다. 요청 부서가 먼저 제공할 자료가 있으면 함께 안내합니다. 아직 협의하지 않은 기한은 희망일로 표시합니다.
3. **파일첨부**에 요청 대상 목록이나 회신용 양식이 있으면 연결합니다. 첨부 없이 회신할 수 있으면 본문에 필수 항목을 적습니다.
4. **연관문서**에 요청의 근거가 되는 이전 기안이나 협의 기록이 있을 때 연결합니다.

## 완성 예시 · 가상 재고 확인 요청

| 입력 칸 | 작성값 |
|---|---|
| 제목 | 포장자재 품목별 실물 재고 확인 요청 |
| 파일첨부 | 품목 목록 1부, 작성자가 실제 파일 연결 예정 |
| 연관문서 | 없음 |

**기안 내용**

> **협조 요청**
>
> 자재 재고 기준을 맞추기 위해 물류운영팀에 첨부 목록의 포장자재 5개 품목 실물 수량 확인을 요청드립니다.
>
> **회신 항목과 희망 기한**
>
> 품목별 수량과 확인 시각을 11월 20일 15시까지 이 문서의 댓글로 회신해 주세요. 장부와 차이가 있는 품목은 보관 위치도 적어 주세요. 희망 기한에 확인이 어려운 품목은 가능한 회신 시각을 알려 주세요.

**작성자 확인**　품목 목록과 수량 단위가 본문 요청과 맞는지, 물류운영팀이 첨부를 열 수 있는지 확인합니다. 희망 기한은 상대 부서의 회신이 오면 합의 상태를 갱신합니다.

## BEST 사례 · 두 부서의 결과물이 이어지는 요청

다음 주의 자재 수불 확인을 위해 두 부서에 순서대로 자료를 요청합니다. 물류운영팀 수량 확인을 먼저 받고, 조달관리팀은 차이 품목만 확인합니다. 두 기한은 요청 부서의 희망 일정입니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 포장자재 실물 확인과 차이 내역 대조 협조 요청 |
| 파일첨부 | 가상 대상 품목 8개 목록과 회신표. 실제 파일은 작성자가 연결 |
| 연관문서 | 앞선 재고 점검 기록의 연결 여부 확인 필요 |

**기안 내용**

> **물류운영팀 협조 요청**　11월 20일 11시를 기준으로 목록의 8개 품목을 실사해, 품목별 실물 수량·단위·보관 위치를 회신표에 적어 주세요. 11월 20일 15시까지 이 문서의 댓글에 회신표를 공유해 주시면 됩니다.
>
> **조달관리팀 협조 요청**　물류운영팀 회신표에서 장부와 차이가 있는 품목을 대상으로, 11월 20일 11시까지의 입고 기록과 미반영 건을 대조해 주세요. 품목별로 근거 문서와 확인 상태를 적어 11월 23일 12시까지 같은 문서의 댓글로 회신해 주세요.
>
> **일정 조정**　첫 회신이 늦어질 경우 가능한 회신 시각을 알려 주세요. 요청 부서에서 두 번째 회신 기한을 협의하겠습니다. 이번 요청은 차이 근거를 확인하는 범위입니다.

**작성자 확인**　실사 기준 시각과 장부 조회 기준이 같은지, 두 부서가 회신표를 열 수 있는지, 첫 회신 지연 시 두 번째 기한을 조정할 담당을 확인합니다. 수량이나 장부를 직접 변경할 요청이 있다면 필요한 결정을 별도로 확인합니다.

제출 전에는 작업 대상과 단위가 분명한지, 회신 요청일과 실제 합의일을 구분했는지, 연결한 자료를 상대 부서가 열 수 있는지 확인합니다.
