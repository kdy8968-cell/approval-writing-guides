# VOC 리포트 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

고객 의견의 주요 내용과 대응 현황을 공유할 때 사용합니다. 한 건의 클레임에 대한 별도 발생 보고가 필요한 상황은 회사에서 안내한 접수·보고 경로를 확인합니다.

## 작성 전에 준비하기

수집 기간과 채널, 집계 기준, 핵심 의견, 담당자가 확인한 영향과 조치를 정리합니다. 중복 문의를 집계에서 어떻게 처리했는지 알 수 있으면 함께 기록합니다.

| 보고 목적 | 내용이 부족할 때 확인할 질문 | 기록할 내용 |
|---|---|---|
| 최근 고객 의견 요약 | 기간·채널·집계 단위가 무엇인가요? 한 문의에 여러 의견이 있는 경우 어떻게 셌나요? | 총건수와 유형별 건수, 비교 기준과 주요 의견 |
| 반복 문의 원인 파악 | 의견을 어디까지 대조했고 실제로 어떤 영향이 확인됐나요? | 관찰 사실, 확인 중인 원인, 필요한 추가 자료 |
| 조치 현황 공유 | 이미 실행한 내용과 검토 중인 조치는 무엇인가요? | 조치 담당·일정, 실행 기록과 효과 확인 상태 |

개별 문제의 최초 접수와 대응을 기록할 때는 [소비자 클레임 발생서](consumer-claim.md)를 검토합니다. 분모를 확인할 수 없으면 집계 범위와 건수를 씁니다.

집계 기간·채널·단위와 비교 기준이 맞으면 제공된 수치로 작성합니다. 채널별로 중복 접수의 처리 방법이 다르거나 한 접수에 여러 유형을 부여해 합계가 달라지면 비교에 사용할 단위를 먼저 확인합니다. 먼저 초안이 필요하면 **확인 전 초안**으로 표시하고, 서로 다른 기준의 수치에는 각각 범위를 붙입니다. 통합 총건수·비중·증감률은 계산에 필요한 기준이 확인된 뒤 사용합니다.

## 작성 화면에 넣기

1. **리포트 내용**에 집계 기간, 채널, 전체 건수와 핵심 의견을 적습니다.
2. 이어서 확인된 영향, 안내·답변 상태, 진행할 개선 조치와 담당·일정을 적습니다. 미확인 영향이나 제안 단계의 조치는 그 상태를 표시합니다.
3. **파일 첨부**에는 필요한 집계 근거를, **이미지 첨부**에는 설명에 필요한 이미지를 연결할 수 있습니다. 이미지 수와 형식은 화면에서 확인합니다. 고객 식별 정보는 필요한 범위로 제한합니다.
4. **연관문서**에 앞선 리포트나 해당 조치의 승인 문서가 있으면 연결합니다.

## 완성 예시 · 가상 온라인 문의 집계

| 입력 칸 | 작성값 |
|---|---|
| 제목 | 온라인 문의 VOC 및 배송 일정 안내 검토 |
| 파일 첨부 | 가상 문의 집계표, 작성자가 실제 파일 연결 예정 |
| 이미지 첨부 | 없음 |
| 연관문서 | 없음 |

**리포트 내용**

> **집계 결과**
>
> 11월 2일부터 6일까지 온라인 문의 12건을 접수 건 기준으로 집계했습니다. 배송 일정 확인 문의는 5건입니다.
>
> **확인 결과와 조치**
>
> 담당자가 기존 배송 일정 안내의 게시 위치를 확인했습니다. 안내 위치와 문구를 개선하는 방안은 담당 부서와 검토 중입니다. 시행 일정과 문의 감소 여부는 아직 확인되지 않았습니다.

**작성자 확인**　12건과 5건이 동일한 기간·채널 기준인지, 첨부에 고객을 식별할 수 있는 자료가 있는지 확인합니다. 개선안의 검토 상태를 실행이나 효과 확인으로 바꾸지 않습니다.

## BEST 사례 · 접수 중복과 복수 유형이 함께 있는 경우

11월 9–13일 온라인 문의 12건과 매장 접수 7건이 있습니다. 두 채널에 공통 문의 ID 3건이 있으며, 각 채널 안에서는 ID가 중복되지 않았습니다. 주유형을 한 건에 하나씩 부여할지, 복수 유형을 별도로 셀지에 따라 합계가 달라집니다.

“두 채널 공통 ID 3건을 한 접수로 합치고, 유형 비교는 주유형 하나를 기준으로 할까요?”를 확인합니다. 가상 답변에서는 공통 ID를 합치고, 대표 유형 하나씩으로 비교하기로 했습니다. 유형별 중복 태그 분석은 별도입니다. 중복 규칙을 확인하기 전에는 아래 통합 수치 대신 채널별 원접수 건수만 제시합니다.

| 입력 칸 | 작성값 |
|---|---|
| 제목 | 11월 9–13일 온라인·매장 VOC와 안내 점검 |
| 리포트 내용 | 아래 요약과 유형별 표 |
| 파일 첨부 | 가상 중복 제거 및 주유형 집계표. 작성자가 식별 정보 표시를 확인한 뒤 연결 |
| 이미지 첨부 | 없음 |
| 연관문서 | 없음 |

**리포트 내용**

> **접수 범위와 집계 기준**
>
> 11월 9–13일 온라인 12건, 매장 7건을 접수했습니다. 두 채널에 공통으로 기록된 문의 ID 3건을 하나씩 합쳐 고유 접수 16건을 집계했습니다. 유형은 접수마다 대표 유형 하나를 부여했습니다.

| 대표 유형 | 고유 접수 건수 |
|---|---:|
| 배송 일정 | 7 |
| 제품 정보 | 5 |
| 매장 이용 | 4 |
| 합계 | 16 |

> **확인 결과와 조치**
>
> 담당자가 배송 예정일 안내가 게시된 위치를 확인했습니다. 안내 문구와 위치를 조정하는 방안을 검토 중입니다. 적용 날짜는 미정이며 적용 뒤 문의 건수를 다시 확인할 계획입니다.

**작성자 확인**　원접수 19건에서 중복 3건을 제외한 16건과 유형별 합계가 맞는지 확인합니다. 전주와 채널 또는 집계 단위가 다르면 비교 수치를 보류합니다. 안내 개정의 실행 여부와 효과는 각각 확인합니다.
