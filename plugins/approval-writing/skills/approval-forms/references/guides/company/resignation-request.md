# 퇴사 신청서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

퇴직 의사를 신청하고 최종 근무일, 급여명세서 수령 주소, 회사 계정 정보를 전달할 때 사용합니다. 지급일 안내 또는 동의 항목이 있으면 신청자가 직접 확인합니다.

## 작성 전에 준비하기

입사일, 최종 근무일, 소속과 직위, 급여명세서 수령 이메일, 현재 사용하는 회사 계정의 종류를 확인합니다.

### 메모에서 빠진 내용만 확인하기

- **퇴직 의사를 알리는 단계**라면 신청서 제출에 필요한 날짜와 확인할 내용을 먼저 정리합니다. 최종 근무일이 아직 협의 중이거나 퇴직일과 다르면 작성자에게 어떤 날짜를 넣을지 확인합니다.
- **인계 일정이 정해진 경우** 본인이 확인한 인계 범위와 날짜를 적습니다. 협의 중이면 본문에 현재 상태를 표시합니다.
- **회사 계정이 있는 경우** 사용 중인 시스템 종류를 확인합니다. 계정 식별 정보가 필요할 때는 화면에 직접 입력합니다.
- **지급 안내나 개인 정보 입력이 필요한 경우** 원문과 선택은 본인이 확인합니다. 날짜, 동의 여부나 지급 조건을 추정해 채우지 않습니다.

최종 근무일과 본인의 요청이 확인되면 **퇴직 사유**를 작성합니다. “말일에 그만둔다”처럼 실제 마지막 근무일과 인사상 퇴직일이 섞여 있으면 **최종 근무일**에 넣을 날짜를 먼저 묻습니다. 사용자가 초안을 먼저 요청하면 **확인 전 초안**으로 표시하고 날짜는 확인 사항에 둡니다. 동의와 개인 정보는 본인이 화면에서 확인합니다.

## 작성 화면에 넣기

1. **소속**, **직위**, **입사년월일**, **최종 근무일**을 확인합니다. 직위는 실제 화면에서 해당하는 값을 선택합니다.
2. **생년월일**이나 **개인이메일** 입력란이 있으면 신청자가 직접 입력합니다. 이메일 용도는 화면 안내를 확인합니다.
3. 지급 관련 안내나 **지급일 동의** 항목이 있으면 신청자가 안내를 읽고 직접 선택합니다. 지급 시점과 제출 절차는 담당자에게 확인합니다.
4. **사용중인계정** 표에 회사에서 부여받아 사용 중인 협업 도구·업무 관리 시스템·온라인 판매 시스템 등 계정 정보를 적습니다. 해당 계정이 없으면 비워 둡니다. 비밀번호는 기재하지 않습니다.
5. **퇴직 사유**에 본인이 확인한 사유를 작성합니다. 해당되는 **파일첨부**, **연관문서**가 있으면 연결합니다.

## 가상 예시

가상 제품제조팀 사원이 최종 근무일을 확인한 뒤 퇴직을 신청합니다. 업무 인계 일정은 담당자와 협의 중입니다.

| 화면 항목 | 가상 입력값 |
|---|---|
| 제목 | 퇴사 신청서 |
| 소속 | 제품제조팀 |
| 직위 | 사원 |
| 입사년월일 | 2024-04-01 |
| 최종 근무일 | 2026-11-30 |
| 생년월일 | 신청자 직접 입력 |
| 개인이메일 | 신청자가 급여명세서를 받을 주소 직접 입력 |
| 지급일 동의 | 안내 전문 확인 후 신청자가 직접 선택 |
| 사용중인계정 | 아래 표 |
| 퇴직 사유 | 아래 본문 |
| 파일첨부 | 없음 |
| 연관문서 | 없음 |

| 협업 도구 | 업무 관리 시스템 | 온라인 판매 시스템 | 기타 |
|---|---|---|---|
| 사용 중인 회사 계정을 신청자가 직접 입력 | 비움 | 비움 | 비움 |

**퇴직 사유**

> 개인 사정으로 퇴직을 신청합니다. 최종 근무일은 11월 30일입니다. 진행 중인 작업과 공용 자료 목록을 정리하고 있으며, 인계받을 담당자와 일정은 확인 중입니다.

**작성자 확인**

입사일과 최종 근무일, 급여명세서 수령 이메일, 동의 선택을 다시 확인합니다. 사용 중인 계정과 인계 사항은 본인이 확인한 내용으로 작성합니다.

## BEST 사례 · 최종 근무일과 퇴직 처리 예정일이 다를 때

가상 신청자는 “12월 4일까지 근무하고 12월 7일에 퇴직 처리 예정”이라는 일정을 전달받았습니다. 최종 근무일은 12월 4일로 확인했으며 인계 자료 목록은 준비 중입니다. 지급일 동의는 본인이 아직 선택하지 않았습니다.

| 화면 항목 | 가상 입력값·확인 사항 |
|---|---|
| 최종 근무일 | 2026-12-04. 인사 처리 예정일과 구분 |
| 지급일 동의 | 신청자가 화면 안내를 읽은 뒤 직접 선택 |
| 사용중인계정 | 협업 도구와 온라인 판매 시스템 계정의 필요한 식별값을 직접 입력. 사용하지 않는 항목은 비움 |
| 퇴직 사유 | 아래 본문 |
| 파일첨부·연관문서 | 관련 기록을 직접 확인한 뒤 해당되는 경우 연결 |

**퇴직 사유**

> 개인 사정으로 퇴직을 신청합니다. 12월 4일 최종 근무일까지 진행 중인 작업과 공용 자료 목록을 정리하겠습니다. 인계받을 담당자와 인계 시점은 협의 중입니다.

**작성자 확인**　최종 근무일과 별도로 안내받은 인사 처리 일정이 필요한 경우 담당자와 대조합니다. 급여명세서 수령 주소와 지급일 동의는 본인이 실제 화면에서 확인합니다. 인계 약속과 회사 계정 처리 상태는 확인된 범위만 적습니다.
