# 지출결의서 작성 가이드

> 공개용 작성 예시입니다. 입력 항목·선택지·절차는 예시이며, 실제 작성 화면과 소속 조직의 기준을 따릅니다. 사례의 조직·인물·수치·일정은 가상입니다.

업무 비용을 정산하거나 업체에 대금을 지급할 때 사용합니다. 누가 먼저 결제했는지, 지금 누구에게 어떤 금액을 지급해야 하는지부터 확인하세요.

## 작성 전에 준비하기

업무 목적과 결제 내역 또는 지급할 거래를 확인합니다. 품목·수량·부가세 포함 금액과 증빙을 대조하고, 선행 기안과 지급 약정일이 있으면 함께 확인합니다.

| 지급 형태 | 목적 | 자료에서 답을 찾을 질문 |
|---|---|---|
| 개인경비 사용 | 개인이 이미 결제한 업무 비용을 정산 | 누가 결제했으며 정산 대상 금액은 얼마인가요? 영수증에 개인 사용분이 함께 있으면 업무 사용분을 어떻게 구분했나요? |
| 법인카드 사용 | 법인카드 결제 내역과 업무 목적을 정리 | 어느 기간의 어떤 거래를 정리하나요? 건별 사용 목적과 증빙이 있나요? 별도로 지급할 금액이 있나요? |
| 외부지급 요청 | 회사가 거래 상대에게 대금을 직접 지급 | 지급 대상·금액과 부가세 포함 여부는 확인됐나요? 지급 요청일에 근거가 있나요? 선행 기안의 금액이나 조건과 달라진 내용이 있나요? |

메모와 증빙으로 지급 형태, 이번 결의 금액, 지급 상대가 확인되면 초안을 작성합니다. 지급 주체·상대가 불명확하거나 증빙과 합계가 다르면 결과를 바꾸는 질문부터 묻습니다. 예를 들어 “카드전표 55,000원 중 취소된 11,000원이 이번 결의에 포함되나요?”처럼 어느 금액의 처리를 확인할지 적습니다. 사용자가 먼저 초안을 요청했다면 확인된 내용만 작성하고 **확인 전 초안**으로 표시합니다. 결의액이나 지급 상대가 미확인이면 작성자 확인에 남겨 해당 값의 입력을 보류합니다.

## 작성 화면에 넣기

1. **제목**에 품목이나 업무와 정산·지급 목적을 적습니다. **소속 부서**를 확인하고 **지급 형태**를 선택합니다. 지급 형태와 항목의 실제 명칭 및 필수 여부는 화면에서 확인합니다.
2. **지급 요청일**은 거래 조건이나 정산 일정에 맞춰 입력합니다. 입력이 필요한지 화면과 담당 안내를 확인합니다.
3. **지출 항목**에 **품목**, **수량**, **금액 (부가세 포함)**을 증빙 단위에 맞춰 행별로 입력합니다. 한 행에서 품목 두 묶음의 총액이 110,000원이면 금액 칸에 110,000원을 적습니다. 여러 행의 합계를 이번 결의 대상 금액과 대조합니다.
4. **입금계좌(외부 or 개인)**가 필요한 경우 은행, 예금주, 계좌번호, 연락처를 작성자가 화면에 직접 입력합니다.
5. **지출 사유**에 구입 또는 사용 목적, 지급 대상, 금액과 지급 요청 근거를 적습니다.
6. **파일첨부**에 증빙을 연결하고 **연관문서**에 선행 기안이 있으면 등록합니다.

## 가상 예시 1 · 개인경비 사용

물류운영팀 담당자가 출고용 라벨 한 묶음을 개인 결제했고, 영수증에서 12,100원(부가세 포함)을 확인했습니다. 지급 요청일 자료는 없습니다.

| 입력 칸 | 복사·선택할 값 |
|---|---|
| 제목 | 출고용 라벨 개인경비 정산 요청 |
| 소속 부서 | 물류운영팀 |
| 지급 형태 | 개인경비 사용 |
| 지급 요청일 | 미정. 입력 필요 여부는 화면 확인 |
| 지출 항목 | 출고용 라벨 · 1묶음 · 12,100원 |
| 입금계좌(외부 or 개인) | 필요한 경우 작성자가 화면에 직접 입력 |
| 파일첨부 | 개인 결제 영수증 · 첨부 예정 |
| 연관문서 | 제공된 자료에서 확인되지 않음 |

**지출 사유**

> 출고 작업에 사용한 라벨 1묶음의 개인 결제 비용 12,100원(부가세 포함)에 대한 정산을 요청드립니다.

**작성자 확인**　영수증의 품목·합계와 정산 대상이 일치하는지 확인합니다. 실제 첨부 파일과 계좌 입력 필요 여부를 화면에서 확인합니다.

## 가상 예시 2 · 법인카드 사용

물류운영팀이 11월 16일과 17일에 출고 작업용 테이프와 완충재를 법인카드로 결제했습니다. 두 영수증에서 각각 22,000원과 33,000원(부가세 포함)을 확인했고 별도 지급 건은 없습니다.

| 입력 칸 | 복사·선택할 값 |
|---|---|
| 제목 | 출고용 소모품 법인카드 사용 내역 |
| 소속 부서 | 물류운영팀 |
| 지급 형태 | 법인카드 사용 |
| 지급 요청일 | 별도 지급 없음. 화면 입력 여부 확인 |
| 지출 항목 1 | 테이프 · 2상자 · 22,000원 |
| 지출 항목 2 | 완충재 · 1상자 · 33,000원 |
| 입금계좌(외부 or 개인) | 별도 지급 없음. 화면 입력 여부 확인 |
| 파일첨부 | 카드 영수증 2건 · 첨부 예정 |
| 연관문서 | 제공된 자료에서 확인되지 않음 |

**지출 사유**

> 11월 16–17일 출고 작업용 테이프와 완충재 구입에 사용한 법인카드 내역을 정리합니다. 두 건의 합계는 부가세를 포함해 55,000원입니다.

**작성자 확인**　카드 사용일, 건별 증빙과 합계 55,000원을 대조합니다. 카드 사용과 별도 지급이 함께 필요한 경우 지급 대상을 확인합니다.

## 가상 예시 3 · 외부지급 요청

조달관리팀이 출고용 포장자재 2묶음을 주문했습니다. 거래 명세의 부가세 포함 합계는 110,000원이고, 거래처와 2026년 11월 20일 지급을 협의했습니다.

| 입력 칸 | 복사·선택할 값 |
|---|---|
| 제목 | 출고용 포장자재 구입대금 지급 요청 |
| 소속 부서 | 조달관리팀 |
| 지급 형태 | 외부지급 요청 |
| 지급 요청일 | 2026-11-20 |
| 지출 항목 | 포장자재 · 2묶음 · 110,000원 |
| 입금계좌(외부 or 개인) | 필요한 경우 작성자가 화면에 직접 입력 |
| 파일첨부 | 거래 명세 및 확인된 증빙 · 첨부 예정 |
| 연관문서 | 선행 기안이 있는 경우 연결 |

**지출 사유**

> 출고용 포장자재 2묶음의 구입대금 110,000원(부가세 포함) 지급을 요청드립니다. 지급 요청일인 2026년 11월 20일은 거래처와 협의한 날짜입니다.

**작성자 확인**　지급 상대, 지급 요청일, 증빙 금액을 대조합니다. 계좌 입력이 필요하면 예금주와 계좌를 원자료로 확인합니다.

## BEST 사례 · 선행 승인과 분할 지급

가상 승인서는 포장 상자 4묶음, 부가세 포함 220,000원을 한도로 승인했습니다. 이번에는 먼저 납품한 2묶음에 대한 지급만 요청합니다. 발주서 단가는 묶음당 55,000원(부가세 포함)이며, 거래 명세에 1차분 수량과 금액이 따로 표시돼 있습니다.

| 확인 항목 | 자료에서 확인한 값 | 이번 입력이나 처리 |
|---|---|---|
| 선행 승인 범위 | 4묶음 · 220,000원 | **연관문서**에 원승인 연결 |
| 1차 납품과 지급 | 2묶음 × 55,000원 = 110,000원 | **지출 항목**에 포장 상자 · 2묶음 · 110,000원 |
| 남은 발주분 | 2묶음 · 110,000원 | 이번 결의 합계에서 제외. 이후 납품과 지급은 별도 확인 |
| 지급 요청일 | 2026-11-20, 1차분 협의일 | **지급 요청일**에 입력 |

**지출 사유**

> 포장 상자 발주 4묶음 중 1차 납품한 2묶음의 대금 110,000원(부가세 포함)을 지급 요청드립니다. 지급 요청일은 11월 20일이며, 잔여 2묶음은 이후 납품 내역을 확인합니다.

**작성자 확인**　**지급 형태**는 외부지급 요청입니다. 발주서와 1차 납품·증빙을 대조하고 **파일첨부**에 실제 근거를 연결합니다. 이전 지급 기록에서 같은 1차분이 중복되지 않는지 확인합니다. 증빙이 전체 발주액만 표시하면 1차 금액의 근거를 확인한 뒤 입력합니다.

지급 형태에 따라 보이는 입력란, 업무상 필요한 증빙과 지급 일정은 실제 작성 화면과 담당 기준으로 확인합니다. AI에 초안을 요청할 때는 입력값, 지출 사유, 작성자 확인을 구분해 달라고 하고 계좌·연락처는 화면에서 직접 처리합니다.
