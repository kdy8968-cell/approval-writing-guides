1. 보고 요약

핵심 결과 또는 현재 상태: [무엇을 확인했는지 또는 어디까지 진행했는지 적습니다.]

중요한 차이 또는 영향: [보고받는 사람이 알아야 할 차이·영향을 적습니다. 없으면 이 항목을 삭제합니다.]

이번 판단 요청: [판단받을 사항을 짧게 적습니다. 공유만 하는 보고이면 ‘공유 목적’으로 적고 없는 결정을 만들지 않습니다.]

2. 주요 내용과 근거

업무 목적 또는 기존 기준: [상단 입력 칸을 반복하지 않고 내용 이해에 필요한 목적·기존 기준이 있을 때만 적습니다.]

실제로 수행하거나 확인한 내용: [보고 목적에 맞는 소제목·표·목록으로 정리합니다. 원자료의 전문 내용은 필요한 깊이로 남깁니다.]

수치·비교 기준과 출처: [수치가 있으면 단위·기간·대상·분모·잠정 여부·자료 원천을 필요한 만큼 적습니다. 없는 지표는 만들지 않습니다.]

3. 차이·문제와 확인 필요사항

[확인된 차이·문제, 원인이 확인됐는지 또는 추정인지, 남은 확인을 나눠 적습니다. 해당 없으면 이 절을 삭제합니다.]

4. 후속 조치

[무엇을 누가 언제 할지, 이미 합의됐는지 또는 제안·미정인지 구분합니다. 이번에 판단받을 구체 사항이 있으면 함께 적습니다. 없는 담당·일정·권한은 만들지 않고 조치가 없으면 이 절을 삭제합니다.]
