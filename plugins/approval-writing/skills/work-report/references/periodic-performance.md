# 실적 보고 — 유형별 지침

SKILL.md가 실제 전달·판단 목적에 맞춰 참고하는 자료입니다. 사용자가 이 파일을 먼저 선택할 필요는 없습니다. 화면 주분류는 하나지만 복합 목적은 다른 지침의 필요한 절을 함께 참고해 상세를 설계합니다. [공통 인터뷰·입력·출력 기준](common-interview-output.md)의 사실·계산·민감정보·출력 분리 기준을 함께 적용합니다. 필요한 질문만 하고 명확한 사실에 대한 재승인 질문을 반복하지 않습니다.

## 언제 고르나요?

정기·비정기·일회성 여부와 관계없이 일정 기간이나 활동 단위의 실적과 중요한 차이를 정리할 때 사용합니다. 출고량·작업시간·상품 판매·방송 실적 등이 해당합니다. 반복 주기는 필수 조건이 아니며 매번 새 프로젝트를 만든다는 뜻도 아닙니다.

행사 전체의 수행·운영 결과가 중심이면 ‘업무 결과 보고’, 진행 중인 단계와 막힌 부분이 중심이면 ‘중간 진행 보고’, 특정 질문에 답하거나 대안을 판단하는 것이 중심이면 ‘조사·검토 보고’를 주분류로 검토합니다. 일회성 행사도 실적 파악이 주목적이면 ‘실적 보고’일 수 있습니다. 화면 주분류 하나와 참고지침 수는 다르므로 필요한 결과·분석·후속 절을 함께 참고하고 억지로 별도 문서로 나누지 않습니다.

## 이 유형에서 확인할 내용

| 확인할 내용 | 질문할 내용 | 피할 오류 |
|---|---|---|
| 대상·범위 | 어느 제품·채널·공정의 실적인가요? 단위는 무엇인가요? | 서로 다른 범위 혼합 |
| 계획·실적 | 실제 계획이 있었나요? 같은 기준의 실제값인가요? | 없는 목표·달성률 생성 |
| 비교 조건 | 영업일수·상품·할인·집계 조건이 같나요? | 조건 차이를 성과로 오인 |
| 차이와 원인 | 무엇이 달라졌고 원인이 기록으로 확인됐나요? | 추정 원인을 확정 |
| 잠정·확정 | 취소·환불·누락·마감 조정이 끝났나요? | 잠정값을 확정으로 표시 |
| 후속 | 공유만 하나요, 지원·변경 판단이 필요한가요? | 보고만으로 새 권한 발생 |

## 본문 구성

1. 핵심 실적: 가장 중요한 결과와 주의할 점을 먼저 적습니다.
2. 실적과 비교: 필요한 지표만 표로 정리합니다. 계획이 없으면 계획·달성률 열을 만들지 않습니다. 단위·집계 범위·원천을 남깁니다.
3. 차이와 확인 내용: 중요한 차이의 확인된 이유, 추정, 아직 모르는 점을 구분합니다.
4. 후속 조치와 판단 요청: 실제 필요한 경우만 적습니다. 정해진 실행과 담당·일정을 연결하되 미정 값을 만들지 않습니다.

매월 같은 지표는 지표명·단위·집계 조건을 유지합니다. 원천·정의가 바뀌면 변경 사실을 설명합니다. 긴 품목별 표는 상세 자료로 연결하고 본문에는 판단할 지표와 예외를 남깁니다. 일부 자료만 확보했으면 전체 실적으로 일반화하지 않습니다. 필요 없는 빈 목차는 생략할 수 있으며 분량과 절 개수를 강제하지 않습니다.

## 필요한 경우에만 볼 완성 예시

[가상 BEST 예시](#가상-best-예시) 절은 이 유형의 확인 질문·입력 칸 값·완성 HTML·작성자 확인을 담고 있습니다. 사용자가 완성 형태를 보고 싶거나 형식 비교가 필요할 때 참고합니다. 실제 자료가 부족할 때 예시로 사실을 대신 채우지 않습니다. 관련 없는 유형의 예시까지 일괄 읽지 않습니다.

최종 본문 단계에서는 [디자인 기준](design.md)과 [HTML 기본틀](../assets/report-body.html)을 적용합니다. 목차는 보고 내용에 맞게 바꿀 수 있습니다. 외부 참고자료의 의미와 적용 범위는 [공통 기준의 참고 자료](common-interview-output.md#참고-자료와-적용-범위)에 있습니다.

## 가상 BEST 예시

이 예시는 질문과 답변이 입력값과 본문으로 이어지는 흐름을 보여 줍니다. 목차는 실제 보고 목적에 맞게 조정합니다.

> 아래 상황과 수치, 조직명, 일정은 작성 연습을 위한 가상 예시입니다.

### 짧은 요청과 인터뷰

처음 요청: “9월 원료 포장 실적 보고를 써 주세요. 계획보다 적게 했습니다.”

AI의 확인 질문:
1. 포장 수량의 단위와 계획·실적 범위가 같나요? 원집계 자료가 있나요?
2. 줄어든 이유를 확인한 기록이 있나요? 아직 원인을 모르면 그렇게 남기겠습니다.
3. 이번에는 실적을 공유하나요, 인력·일정 등 추가 결정을 받으려 하나요?

가정한 답: 작성 조직은 제조팀이고 보고 대상 업무는 원료 포장 실적이다. 보고 기간은 2026년 9월 1일부터 30일까지다. 같은 완제품 봉 단위로 계획 10,000봉, 실적 9,500봉이며 예시_월간포장집계.xlsx의 월간집계에 같은 범위로 정리돼 있다. 정비일지에 포장기 정지 6시간이 있으나 미달 전체가 이 때문인지는 분석 전이다. 포장 운영 담당이 다음 계획 수립 전에 원인을 확인하며 이번에 인력·예산 승인은 요청하지 않는다.

### 가. 입력 칸 — 완성 예시

| 입력 칸 | 값 |
|---|---|
| 문서 제목 | 9월 원료 포장 실적 보고 — 계획 대비 미달 원인 추가 확인 |
| 소속 부서 | 제조팀 — 실제 화면의 조직 확인 |
| 어떤 보고인가요? | 실적 보고 |
| 보고 대상 업무 | 원료 포장 실적 |
| 보고 기간 | 2026-09-01 ~ 2026-09-30 |

이 표는 읽기용입니다. 실제 출력에서는 텍스트 항목별 복사값과 선택·달력 설정 안내를 분리합니다. 표 전체를 본문에 붙이지 않습니다.

### 나. 보고 내용 — 완성 HTML 예시

```html
<div style="font-family:sans-serif;font-size:14px;line-height:1.7;color:#30343B;">
<h3 style="font-size:16px;font-weight:700;margin:18px 0 8px;">1. 핵심 실적</h3>
<p style="margin:0 0 10px;">포장 실적은 9,500봉으로 계획의 95.0%입니다. 계획보다 500봉 적었으며 전체 차이의 원인은 추가 확인 중입니다.</p>
<h3 style="font-size:16px;font-weight:700;margin:18px 0 8px;">2. 실적과 비교 기준</h3>
<table style="border-collapse:collapse;width:100%;font-size:14px;"><thead><tr><th style="border:1px solid #D9DEE5;padding:8px;text-align:left;">항목</th><th style="border:1px solid #D9DEE5;padding:8px;text-align:left;">계획</th><th style="border:1px solid #D9DEE5;padding:8px;text-align:left;">실적</th><th style="border:1px solid #D9DEE5;padding:8px;text-align:left;">차이</th></tr></thead><tbody><tr><td style="border:1px solid #D9DEE5;padding:8px;">완제품 포장 수량</td><td style="border:1px solid #D9DEE5;padding:8px;">10,000봉</td><td style="border:1px solid #D9DEE5;padding:8px;">9,500봉</td><td style="border:1px solid #D9DEE5;padding:8px;">-500봉</td></tr></tbody></table>
<p style="margin:8px 0 10px;">자료: 예시_월간포장집계.xlsx, 월간집계 시트. 계획·실적은 같은 완제품 범위의 봉 수 기준입니다. 달성률은 9,500 ÷ 10,000 × 100으로 계산했습니다.</p>

<p style="margin:0 0 10px;">포장 운영 담당이 다음 계획 수립 전에 정지 시간과 작업별 실적을 대조할 예정입니다. 이번 보고에서는 추가 인력·예산 승인을 요청하지 않습니다.</p>
</div>
```

### 다. 작성자 확인 — 본문 밖 예시

예시 파일은 실제 첨부가 아닙니다. 실제 집계 파일·정비일지 이름과 접근 가능 여부를 확인해 연결합니다. 가상 계획·실적을 회사 실제 숫자로 사용하지 않습니다.

### 이 예시가 보여주는 점

계획이 실제로 있을 때만 달성률을 계산하고, 설비 정지와 미달 전체의 인과관계를 구분합니다. 단순 보고에 새 예산 승인 요청을 만들어 붙이지 않습니다.
