# 업무 결과 보고 — 유형별 지침

SKILL.md가 실제 전달·판단 목적에 맞춰 참고하는 자료입니다. 사용자가 이 파일을 먼저 선택할 필요는 없습니다. 화면 주분류는 하나지만 복합 목적은 다른 지침의 필요한 절을 함께 참고해 상세를 설계합니다. [공통 인터뷰·입력·출력 기준](common-interview-output.md)의 사실·계산·민감정보·출력 분리 기준을 함께 적용합니다. 필요한 질문만 하고 명확한 사실에 대한 재승인 질문을 반복하지 않습니다.

## 언제 고르나요?

행사·출장·방문·교육·회의 등 하나의 업무 또는 특정 단계를 마친 뒤 실제 수행 내용과 결과, 배운 점, 합의·후속 사항을 정리할 때 사용합니다. 특정 단계가 끝났다는 사실과 전체 사업이 완료됐다는 사실은 구분합니다. 매출이 없는 출장·교육도 충분한 결과 보고가 될 수 있습니다.

실적 자체의 현황·차이를 전달하는 것이 중심이면 ‘실적 보고’, 아직 진행 중인 전체 업무의 상태가 중심이면 ‘중간 진행 보고’, 독립적인 비교·검토가 중심이면 ‘조사·검토 보고’를 검토합니다. 행사 결과에 수익 분석이 있거나 출장에 구매 검토가 포함됐다는 이유만으로 자동 분할하지 않습니다.

## 이 유형에서 확인할 내용

| 상황 | 필요한 확인 | 피할 오류 |
|---|---|---|
| 행사·판매 | 실제 진행, 참여·주문·매출 기준, 비용 포함 범위, 취소·환불 | 매출만으로 수익·흑자 단정 |
| 출장·방문 | 실제 방문·면담·관찰, 목적에 대한 확인, 합의와 제안 | 방문·논의를 거래 확정으로 표현 |
| 교육·세미나 | 참석, 주요 학습, 업무 연관, 적용 후보, 시험·공유 계획 | 수료만으로 업무 효과 검증 단정 |
| 협의·회의 | 누가 무엇을 논의·합의했고 무엇이 남았는지 | 상대 발언과 회사 결정을 혼동 |
| 후속 요청 | 바꿀 범위·영향, 남은 검증·협의 | 보고 승인으로 새 계약·인사·지급까지 허용 |

## 본문 구성

1. 핵심 결과: 실제 어떤 일을 마쳤고 무엇을 확인했는지 먼저 적습니다.
2. 수행 내용과 확인 근거: 집계, 전문 관찰, 학습, 실제 협의 결과 중 필요한 내용을 충분히 남깁니다.
3. 평가와 활용: 잘된 점·제약·미확인, 적용 후보와 다음 시험을 구분합니다. 정량 효과가 없으면 관찰과 판단 근거를 설명하며 KPI를 지어내지 않습니다.
4. 후속 조치와 판단 요청: 정해진 실행, 제안, 판단 대기를 구분하고 필요한 경우만 적습니다.

출장 이동표를 모두 본문에 반복할 필요는 없습니다. 다만 전문적인 품평·현장 비교·기술 관찰·거래 조건은 핵심 요약 뒤 충분히 남길 수 있습니다. 긴 기록은 세부 절이나 실제 첨부와 연결하고 단순 소감으로 축약하지 않습니다. 매출·이익·받을 돈·지급 완료는 다른 사실입니다. 실제 비용 정의와 인건비·운송비 등 포함 여부를 표시합니다. 필요 없는 빈 목차는 생략할 수 있습니다.

### 행사·출장·교육별 추가 질문

- 행사: 실제 인원과 제공량은 구분했나요? 행사 전후만으로 매출 효과를 단정할 수 있나요?
- 출장: 무엇을 관찰했나요? 누가 무엇에 합의했나요? 현지 합의·구매 제안·계약 체결을 구분했나요?
- 교육: 실제 배운 내용은 무엇인가요? 업무 적용은 계획인가요, 시험했나요? 미정 적용 날짜를 만들지 않습니다.
- 회의: 논의·합의·미합의·내부 검토를 분리했나요? 회의가 끝났다는 이유로 전체 사업이 완료된 것은 아닙니다.

### 쇼핑라이브 등 운영 결과의 상세 목차 예

아래는 방송 결과 보고의 목적에 맞게 선택할 수 있는 구성 예입니다. 보유한 자료의 깊이만큼 작성하고 없는 목표·지표·이유를 만들지 않습니다.

1. 보고 요약: 중요한 결과·현재 상태·영향, 이번에 판단할 사항이 있는지를 먼저 설명합니다.
2. 목표와 운영 개요: 실제 정해 둔 목표가 있을 때만 비교합니다. 목표가 없으면 만들지 않습니다. 상품·운영 조건 등 해석에 필요한 내용만 남기고 상단 업무명·보고 기간을 반복하지 않습니다.
3. 판매·시청과 반응 결과: 원자료에 존재하는 지표만 표로 재사용합니다. 주문·결제·취소·환불·순매출·정산값을 구분하고 기간·분모·집계 범위·부가세 포함 여부를 확인합니다. 방송별 사실과 해당 플랫폼의 시청·유입·반응 지표 정의를 유지합니다.
4. 운영 중 문제와 고객 반응: 실제 확인한 운영 문제·질문·반응, 자료로 확인한 이유와 추정을 나눕니다. 진행이 끝났다는 이유로 정산도 확정됐다고 쓰지 않습니다. 비교 자료가 없으면 없음을 밝히고 전환율·이익률·ROI를 근거 없이 계산하지 않습니다.
5. 다음 조치와 판단 요청: 합의된 후속·추가 확인·제안과 이번 판단 범위를 구분합니다. 담당·일정이 없으면 미정으로 남깁니다.

플랫폼 엑셀·원집계·운영 메모를 한 번 받아 표와 핵심 요약으로 재사용합니다. 개별 화면 캡처의 재타이핑이나 별도 PPT 제작을 필수로 요구하지 않습니다. 본문에는 결과·판단을 이해할 핵심을 남기고 방송별 상세 근거를 연결합니다. 세 번의 방송을 비교해 채널을 계속할지 결정하려는 목적이면 ‘조사·검토’를 주분류로 두고 실적·결과 지침의 필요한 절을 함께 참고할 수 있습니다.


## 필요한 경우에만 볼 완성 예시

[가상 BEST 예시](#가상-best-예시) 절은 이 유형의 확인 질문·입력 칸 값·완성 HTML·작성자 확인을 담고 있습니다. 사용자가 완성 형태를 보고 싶거나 형식 비교가 필요할 때 참고합니다. 실제 자료가 부족할 때 예시로 사실을 대신 채우지 않습니다. 관련 없는 유형의 예시까지 일괄 읽지 않습니다.

최종 본문 단계에서는 [디자인 기준](design.md)과 [HTML 기본틀](../assets/report-body.html)을 적용합니다. 목차는 보고 내용에 맞게 바꿀 수 있습니다. 외부 참고자료의 의미와 적용 범위는 [공통 기준의 참고 자료](common-interview-output.md#참고-자료와-적용-범위)에 있습니다.

## 가상 BEST 예시

이 예시는 질문과 답변이 입력값과 본문으로 이어지는 흐름을 보여 줍니다. 목차는 실제 보고 목적에 맞게 조정합니다.

> 아래 상황과 수치, 조직명, 일정은 작성 연습을 위한 가상 예시입니다.

### 짧은 요청과 인터뷰

처음 요청: “주말 음료 시음 행사 결과 보고를 써 주세요. 반응이 좋았고 다음에도 하고 싶습니다.”

AI의 확인 질문:
1. 참여자는 실제 인원인가요, 제공한 잔 수인가요? 반응이 좋다는 근거가 있나요?
2. 판매·비용을 집계했나요? 자료가 없으면 수익 효과는 쓰지 않겠습니다.
3. 다음 행사 자체를 승인받으려 하나요, 이번 안내 방식의 보완을 보고하나요?

가정한 답: 작성 조직은 매장지원팀이고 보고 대상 업무는 주말 음료 시음 행사다. 행사는 2026년 9월 19일부터 20일까지 진행됐다. 예시_시음제공기록.xlsx에는 제공 120잔으로 기록돼 있으며 고유 참여 인원은 따로 세지 않았다. 예시_익명응답요약.xlsx의 익명 응답 54건 중 41건이 제품 설명을 이해하기 쉬웠다고 답했다. 행사에 직접 연결되는 판매 데이터와 전체 비용은 집계하지 않았다. 행사 담당이 다음 운영의 안내문 보완안을 준비하며 보완 일정은 아직 정하지 않았다. 다음 행사 개최·예산은 아직 판단받지 않는다.

### 가. 입력 칸 — 완성 예시

| 입력 칸 | 값 |
|---|---|
| 문서 제목 | 주말 음료 시음 행사 결과 보고 — 향미 안내문 보완 |
| 소속 부서 | 매장지원팀 — 실제 화면의 조직 확인 |
| 어떤 보고인가요? | 업무 결과 보고 |
| 보고 대상 업무 | 주말 음료 시음 행사 |
| 보고 기간 | 2026-09-19 – 2026-09-20 |

읽기용 표입니다. 실제 출력은 항목별 복사값과 선택·달력 설정을 나눕니다. 표 전체를 본문에 붙이지 않습니다.

<h3 style="font-size:16px;font-weight:700;margin:18px 0 8px;">2. 수행 내용과 확인한 반응</h3>

<p style="margin:0 0 10px;">다음 행사 개최와 예산은 이번 보고의 승인 요청에 포함하지 않습니다. 실제 개최 검토 때 필요한 조건을 확인할 예정입니다.</p>

### 다. 작성자 확인 — 본문 밖 예시

실제 익명 응답의 문항·집계 기준과 원자료 접근을 확인합니다. 예시 원자료는 실제 첨부가 아닙니다. 출장·교육 등 다른 결과 보고에 이 예시의 판매·설문 항목을 의무로 추가하지 않습니다.

### 이 예시가 보여주는 점

잔 수·인원·응답 수를 구분하고 좋은 반응을 수익 성과로 바꾸지 않습니다. 후속 준비와 다음 행사 개최·예산 승인을 구분합니다. 비용이 없는 전문 학습·관찰도 해당 근거를 충분히 남길 수 있습니다.
